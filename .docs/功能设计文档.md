# 图片配置标准化功能设计文档

## 作用
- 记录本轮“图片配置标准化”实现方式、数据流与验证结果。

## ./src/lib/showcase.ts
### 作用
- 作为展示区统一清洗层，避免在多个页面重复判断脏图、脏文案和空数据；默认数据定义仅用于命名与标题回退，不再在读取链路里自动写库。
### BLOCKED_SHOWCASE_IMAGE_SEGMENTS
- 屏蔽 `gallery`、`campus`、`seed`、`xgnedu`、`partners` 等历史残留路径。
### TOXIC_SHOWCASE_TEXT_KEYWORDS
- 屏蔽“新概念”及历史证书/院校残留名称。
### MOJIBAKE_SHOWCASE_TEXT_PATTERNS
- 识别历史导入造成的乱码标题，避免首页与列表页直接透出脏数据。
### DEFAULT_CERTIFICATE_TITLES / DEFAULT_CAMPUS_GROUPS
- 内置首页“证书风采 8 条”“学院风采 4 组 8 图”的规则标题与命名数据源。
### ensureShowcaseSeedData()
- 历史补库函数；当前已从首页、列表页与公开接口读取链路移除，避免读请求触发写库。

## ./src/app/(web)/page.tsx
### 作用
- 首页聚合 `setting`、`homeCard`、`gallery`、`campus` 数据，并仅在服务端完成展示区清洗。

### topbarShowContent / topbarBgImage / topbarShowOverlay
- 首页将顶部横幅整段显示、背景图、区块级上层元素显隐接线到设置系统，不新增数据库字段。

### statsText
- 统计横幅文案改为单一字段直读（原 yearsOfEstablishment、totalGraduates、statsLabel 三个字段已在 settings-registry.ts 和 block-registry.ts 中合并为 statsText）；StatsBanner 组件 props 同步更新，直接渲染完整字符串，不再动态拼接年限和人数。

### campuses
- 首页直接读取 `Campus` / `CampusImage` 表，服务端阶段完成学院风采图片、标题清洗。

## 学校专业招生计划数据体系
### ./prisma/schema.prisma
- 新增 `Major` 专业主数据表；`Course.majorId` 和 `HotMajor.majorId` 共同关联 `Major`。
- 新增 `EnrollmentOffering` 招生计划明细表，关联 `Major` 与 `Partner`，保存批次、招生类型、层次、专业代码、年学费、总费用、费用说明、状态等字段。
- `Course` 新增 `priceText`，用于 `/courses` 直接显示 `¥总费用` 或 `--`。
### ./src/lib/enrollment-pricing.ts
- `inheritEnrollmentLevels()` 处理招生表中 `/` 或空白层次继承同学校上一条明确层次。
- `getLowestTotalTuition()` 只从有价格明细中取最低总费用，全部无价格时返回 `--`。
### ./src/lib/enrollment-sync.ts
- `ensureMajor()`、`ensurePartner()`、`ensureCourseForMajor()` 负责专业、学校、课程主数据补齐。
- `upsertEnrollmentOffering()` 保存招生明细后调用 `refreshMajorCoursePricing()`，同步刷新对应课程展示价格。
### ./src/app/api/majors/route.ts
- 提供专业主数据列表和新增接口。
### ./src/app/api/enrollment-offerings/route.ts / ./src/app/api/enrollment-offerings/[id]/route.ts
- 提供招生计划分页筛选、新增、编辑、删除接口。
### ./src/app/manager/enrollment-offerings/page.tsx
- 后台招生计划管理页支持学校/专业筛选、新增、编辑、删除；保存后自动联动 `/courses` 价格。
### ./src/app/(web)/courses/[id]/page.tsx
