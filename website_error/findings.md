## 四、发现的问题清单

### 问题-1: 文章管理"新增"按钮点击后无Dialog弹窗（严重）

| 属性 | 内容 |
|------|------|
| 所属模块 | 一级直出 → 文章管理 |
| 严重程度 | **P1** |
| 问题描述 | 点击"新增文章"按钮后，页面无Dialog弹窗弹出，新增功能无法使用 |
| 复现步骤 | 1. 登录后台 2. 进入文章管理 3. 点击"新增文章"按钮 4. 观察到无弹窗 |
| 期望结果 | 弹出新增文章Dialog表单 |
| 实际结果 | 点击后无任何反应，控制台可能有JS错误 |
| 影响范围 | 文章管理模块无法新增文章 |
| 根因分析 | 文章管理页面的新增按钮可能使用了不同的触发逻辑（如跳转到新页面而非Dialog），或JS报错导致弹窗未渲染 |

### 问题-2: 媒体管理编辑按钮点击超时（严重）

| 属性 | 内容 |
|------|------|
| 所属模块 | 内容管理 → 媒体管理 |
| 严重程度 | **P1** |
| 问题描述 | 点击媒体列表中某行的编辑按钮后，30秒超时无响应 |
| 复现步骤 | 1. 进入媒体管理 2. 点击某媒体行的编辑按钮 3. 等待30秒超时 |
| 期望结果 | 弹出编辑Dialog或Inline编辑 |
| 实际结果 | 按钮点击后长时间无响应，最终超时 |
| 影响范围 | 媒体管理无法编辑单条记录 |
| 根因分析 | 编辑按钮可能绑定了异步加载逻辑（如加载大图预览），或事件监听器异常 |

### 问题-3: 全站图片资源404（一般）

| 属性 | 内容 |
|------|------|
| 所属模块 | 全站所有页面 |
| 严重程度 | P2 |
| 问题描述 | `/uploads/banners/bannerX.jpg` 等图片文件404 |
| 根因分析 | `public/uploads/` 目录下缺少物理图片文件 |
| 影响范围 | 视觉体验，Banner轮播图、媒体预览显示异常 |

### 问题-4: 角色管理只读无CUD（一般）

| 属性 | 内容 |
|------|------|
| 所属模块 | 系统管理 → 角色管理 |
| 严重程度 | P2 |
| 问题描述 | 角色管理页面仅有列表展示，无新增/编辑/删除功能 |
| 根因分析 | 后端 `api/roles` 仅实现GET，前端无操作列 |
| 影响范围 | 无法自定义角色和权限配置 |

### 问题-5: 部分页面缺少分页组件（建议）

| 属性 | 内容 |
|------|------|
| 所属模块 | 多个列表页面 |
| 严重程度 | P3 |
| 问题描述 | courses/news/articles/banners等页面未使用Pagination组件 |
| 根因分析 | 当前数据量小（<20条），全量加载可接受 |
| 影响范围 | 数据量增大后性能下降 |
