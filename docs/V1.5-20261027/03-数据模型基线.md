## 三、核心实体与关系（本轮验收涉及）

### 3.1 内容域

| 实体 | 关键字段 | 关系 |
|---|---|---|
| `Article` | id, title, slug, content, contentType, status, channel | → ContentChannel（1:N） |
| `ContentChannel` | articleId, channel, externalId, externalUrl, status, errMsg | 承载幂等 |
| `Category` | id, name, slug, sort | ← Article（N:1） |
| `Tag` | id, name, slug | Article ↔ Tag（M:N） |
| `PublishJob` | id, articleId, status, errMsg, result, scheduledAt | 状态机全链路 |

### 3.2 采集域

| 实体 | 关键字段 | 约束 |
|---|---|---|
| `CollectSource` | id, name, url, parser, enabled, cron | — |
| `CollectItem` | id, sourceId, url, **urlHash**（唯一）, status | 去重靠 urlHash |
| `CollectTask` | id, sourceId, startedAt, finishedAt, result | 运行历史 |

### 3.3 身份域

| 实体 | 关键字段 |
|---|---|
| `User` | id, username, passwordHash, role（ADMIN/EDITOR/VIEWER）, nickname |
| `Role` | 角色定义（42 页权限矩阵来源） |

### 3.4 知识库 / AI 域

| 实体 | 关键字段 |
|---|---|
| `KnowledgeBase` | id, name, cozeDatasetId, status |
| `KnowledgeFile` | id, kbId, filename, mime, status（pending/ready/failed）, trash |
| `LlmProvider` | id, name, kind, apiKey（加密）, priority, enabled |
| `ChatSession` / `ChatMessage` | 会话与消息（AI 客服） |

### 3.5 站点配置域

| 实体 | 关键字段 |
|---|---|
| `Setting` | key（唯一）, value, group |
| Setting 键总数 | **35**（`grep -oE '^\s+[a-zA-Z][a-zA-Z0-9]*:' src/lib/settings-registry.ts` 近似统计，见局限） |

> **注**：`V1.4/06-验收体系.md` 声明 Setting 键 85 个。本轮实测从 registry 结构估算约 35 个顶层定义项。**差异原因未查明**，可能统计口径不同（是否含分组/嵌套）。已登记为局限（08 §局限 L3），本轮不作为验收依据。

## 四、索引策略（本轮相关）

| 查询路径 | 依赖索引 | 状态 |
|---|---|---|
| 文章列表分页 | `Article(status, publishedAt)` | 既有 |
| 采集去重 | `CollectItem(urlHash)` UNIQUE | 既有 |
| 渠道状态查询 | `ContentChannel(articleId, channel)` | 既有 |
| 知识文件列表 | `KnowledgeFile(kbId, trash)` | 既有 |

**本轮不新增索引**（验收轮不改 schema）。

## 五、软删除与生命周期

| 实体 | 策略 | 证据 |
|---|---|---|

| `Upload` | 孤儿扫描清理 | `scripts/scan-orphan-uploads.mjs` |
