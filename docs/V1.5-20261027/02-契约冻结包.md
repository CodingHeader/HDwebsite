# 02 · 契约冻结包（六份）

> **本轮 0 契约变更。** 六份契约沿用 V1.4 冻结状态，`src/contracts/**` 只读。
> 下列为"并行开发所需的接口事实"，不是新设计。若任务卡需要改契约 → 必须走 CCR，本轮不允许。

## 契约唯一源

**唯一源**：`src/contracts/**`（zod schema，机器可校验）

**禁止**：在路由/组件内重复定义 DTO（`AGENTS.md §4`）

实测校验方式：`npm run typecheck`（`tsc --noEmit`）+ 契约单测。

## ① API 契约

### 形态
- 全部 REST，路径前缀 `/api/`
- 路由文件：`src/app/api/**/route.ts`（实测 126 个）
- 统一响应信封（来自 `src/contracts/common.ts`）：

```ts
{ code: number, data?: T, message?: string, fieldErrors?: Record<string,string> }
```

### 本轮涉及的只读接口（验收需要）

| 用途 | 方法 | 路径 | 备注 |
|---|---|---|---|
| 健康检查 | GET | `/api/health` | 返回 200 |
| 文章列表 | GET | `/api/articles?page=1` | 分页信封 |
| 管理端资源 CRUD | GET/POST/PATCH/DELETE | `/api/<resource>` | 由 `crudPageSpecs` 驱动 |
| 审核通过 | POST | `/api/content-hub/...` | 内容中枢链路 |

> **本轮不新增任何 API**。所有验收只调用既有接口。

### 分页格式（沿用）

```ts
{ code: 200, data: { list: T[], total: number, page: number, pageSize: number } }
```

### 幂等语义（沿用）
- 采集去重：`urlHash` 唯一键
- 发布：`ContentChannel.externalId` 承载幂等

### 鉴权要求（沿用）
- 管理端接口：`Authorization: Bearer <JWT>`，缺失 → 401
- 角色校验：ADMIN 全权 / EDITOR 写内容 / VIEWER 只读，越权 → 403

## ② Errors 契约

### 错误体结构

```ts
{ code: number, message: string, fieldErrors?: Record<string, string> }
```

### 码段划分（实测 `src/contracts/common.ts`）

| 段 | 语义 | 典型码 |
|---|---|---|
| 0 | 成功 | 200 |
| 1xxx | 参数/校验 | 1001 校验失败 |
| 2xxx | 认证/权限 | 2001 未认证、2002 无权限 |
| 3xxx | 资源 | 3001 不存在、3002 冲突 |
| 5xxx | 服务端 | 5001 内部错误 |

### 前端如何展示

- `src/lib/manager-fetch.ts`：`isForbidden()` / `errorMessage()` 统一映射
- 未知码 → 通用文案，不透传后端原始 message（防信息泄漏）
- 字段级错误 → `fieldErrors` → `mapFieldErrors()` → 表单逐项标红 + `aria-invalid`

### 本轮相关

- **无新增错误码**。验收中触发 403 时复用 `Forbidden` 组件（`CrudPage.tsx:333`）。

## ③ Identity 契约

### 用户 ID 形态
- 主键 `Int` 自增（与 `ResourceForm` 的 id 处理一致）

### 角色枚举（实测 `src/contracts/auth.ts`）

```ts
ADMIN | EDITOR | VIEWER
```

### Session / JWT 声明
- `JWT_SECRET` ≥32 位（`.env.example`）
- cookie 承载，服务端校验
- 有效期与刷新策略沿用既有实现

### **管理端与用户端的权限边界（越权路径明确禁止）**

| 路径 | 访客 | VIEWER | EDITOR | ADMIN |
|---|---|---|---|---|
| 前台 `/`、`/articles` 等 16 页 | ✅ | ✅ | ✅ | ✅ |
| `/api/articles` GET | ✅ | ✅ | ✅ | ✅ |
| `/api/articles` POST/PATCH/DELETE | ❌ 401 | ❌ 403 | ✅ | ✅ |
| `/manager/**` 页面 | ❌ 重定向登录 | ✅ 只读 | ✅ 按角色 | ✅ 全权 |
| `/api/settings` | ❌ | ❌ 403 | ❌ 403 | ✅ |
| `/api/users` 管理 | ❌ | ❌ | ❌ | ✅ |

**明确禁止的管理端越权**：
- 前台组件不得 import `src/components/manager/**`（边界由 ESLint 守卫）
- 管理端令牌不得泄漏到 `[data-theme="manager"]` 作用域外
- 公开接口（`POST /api/user-actions`）不得要求 JWT —— 实测历史上曾被 CRUD 生成器误覆盖为 405，已修复（changelog V0.9 E3）

## ④ Resources 契约

### 文件 URL 规则
- 上传存 `DATA_DIR/uploads/`
- 对外 URL：`/api/uploads/<filename>` 或 `/uploads/<filename>`（取决于部署）
- 图片域名白名单（`next.config.ts:17-23`）：`mmbiz.qpic.cn`、`www.hd1994.com`、`localhost`

### 上传鉴权
- 管理端上传：需 JWT + EDITOR 以上
- 白名单：按 MIME 魔数校验（ADSR），非扩展名
- 大小限制：20MB（K2）

### 生命周期
- 孤儿扫描：`scripts/scan-orphan-uploads.mjs`
- 备份恢复：`scripts/drill-backup-restore.mjs`

### 知识库上传（ADR-025 约束）
- **仅接受**：`.docx` / `.doc` / `.md` / `.markdown` / `.txt`
- **拒绝**：PDF、图片
