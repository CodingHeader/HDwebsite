# STEP S8（管理端体验）

## V11-UI-01 文章编辑字段补齐（Hark，中）
目标：文章编辑表单补 slug、标签、置顶、推荐、热门、SEO 字段（接口已支持的直通；缺的按契约）
步骤：对照 API/契约列出表单缺失字段清单（入证据）；补表单控件（slug 自动生成+可改、标签多选、三开关、SEO 区）；e2e：编辑并保存全字段回读一致
验收：全部字段可编辑且保存回读一致；slug 冲突有明确报错

## V11-UI-02 媒体库能力补齐（Hark，中）
目标：媒体库补内置图并入、缺失文件标记、搜索、分类
步骤：内置图并入（复制 public 内置资源入库并去重）；孤儿/缺失扫描接入列表标记（D-14 既有孤儿扫描复用）；列表加搜索与分类筛选
验收：四能力可用（e2e 或组件断言）；缺失标记与真实文件状态一致

## V11-UI-03 关联字段选择器（Hark，中）
目标：表单中的数字 ID 关联字段（categoryId/majorId 等）改为搜索下拉选择
步骤：实现通用 RelationSelect（远程搜索 + 缓存 + 可清空）；接入全部手填 ID 的表单（盘点清单入证据）；e2e：选分类保存成功
验收：无任何表单再需手填数字 ID（盘点表全勾）；选择器有防抖与空态

## V11-UI-04 排序全量生效（Hark，小）
目标：列表排序操作对全量数据生效（非仅当前页）
步骤：定位排序实现（按当前页 id 集合排序的缺陷点）；改为按全量条件排序（后端按 sort 字段整体调整或拖拽权重重算）；单测：跨页排序后顺序全局正确
验收：跨页排序结果全局有序；既有分页不受影响

## V11-UI-05 文章编辑/列表对旧 /manager/news 兼容（Hark，极小）
目标：/manager/news 入口重定向到文章管理（旧链接可达）
步骤：新建 /manager/news 页面永久重定向至 /manager/articles
验收：旧链接 308/302 到新址（e2e 或 curl 证据）
