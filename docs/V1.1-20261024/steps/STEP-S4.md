# STEP S4（采集与调度）

## V11-COL-01 调度锁语义与手动执行并发保护（P1，中）
目标：锁过期时间覆盖单批最长执行；手动「立即执行」防并发；失败告警接入 notify
步骤：锁 TTL 与单批上限对齐（10min < 30min 的重复启动窗口消除：心跳续期或 TTL=批次上限+余量）；手动执行入口加运行中互斥（同任务/同源）；采集失败事件接入 notify（collect_failed 已有事件，接手动执行路径）
验收：单批 30 分钟内不会被重复调度（单测/时间推进）；手动连点不产生并发执行；失败有告警记录

## V11-COL-02 cron 语义、开关解绑与时区配置（P1，小）
目标：源级 cron 语义修正或文档化；图片转存开关独立；部署件时区 Asia/Shanghai
步骤：采集源 cron 受总任务门控的语义：实现「源启用即按自身 cron」或在管理端明示门控关系（择一，证据说明）；图片转存开关与「默认入知识库」解绑（独立设置键）；Dockerfile/compose/.env.example 加 TZ=Asia/Shanghai
验收：源 cron 行为与其 UI 提示一致；两开关互不影响（单测）；容器内 date 为 CST
