# STEP S6（LLM 与客服）

## V11-LLM-01 流式超时语义修正（P2，小）
目标：30s 限制改为「空闲超时」（相邻 chunk 间），长回复不再被整流截断
步骤：把整流 30s 定时器改为 last-chunk 空闲计时（如 30s 无新 chunk 才断）；总时长上限另设（如 5 分钟）防挂死，写入证据；mock 流测试：>30s 持续输出不被截断
验收：长回复（mock 60s 流）完整送达；真挂死连接仍会被空闲超时切断

## V11-LLM-02 流式 tokens 计量修正（P2，小）
目标：流式调用 usage 从流尾帧取值；失败重试不重复计数
步骤：流式 usage 解析：有 usage 帧用之；无则估算口径写入证据（保持 ADR-034 偏差）；失败重试路径的 usage 只记最终成功一次；单测：mock 流 usage 正确、重试不双计
验收：mock 流 tokens=流尾值；重试场景无重复记录

## V11-LLM-03 兜底可达性与客服安全模式（P2，中）
目标：限频/配额命中时兜底模型仍被尝试；公众号客服支持安全模式 AES 解密；默认场景与风控频率对齐需求
步骤：限频/配额判断只作用于当前模型，不短路后续兜底链；公众号加密模式：AES 解密支持（配置驱动 safe/compatible/safe 模式）；默认场景与风控频率按需求文档核对并修正（差异入证据）
验收：主模型限频时兜底仍被调用（mock）；AES 密文消息可解密回复（mock）；默认场景/频率与需求一致
