# STEP S7（邮件）

## V11-MAIL-01 SMTP 发送异步化（P1，中）
目标：邮件发送移出主请求路径（后台队列/异步），发布与余额填报不再被 SMTP 阻塞
步骤：梳理同步 await 发送点，改为入队后台处理（复用既有 defer/flushDeferred 机制）；发送超时上限（如 10s）+ 失败标记；单测：主流程不被 SMTP 慢速阻塞（mock 计时）
验收：SMTP 挂起时主流程 <100ms 返回；邮件仍会送达（后台）

## V11-MAIL-02 失败重试、HTML 模板与分组一致性（P1，中）
目标：failed 记录重启后重试；模板改 HTML 且按事件选择；分组提示与种子规则一致
步骤：启动/定时扫描 failed 记录重试（次数上限 + 退避）；HTML 模板按事件类型选择（before_publish/failed/balance/collect）；管理端分组提示文案与 seed 规则对齐（逐条核对入证据）
验收：重启后 failed 被重试（单测）；邮件为 HTML 且事件对应；按提示配置的收件人能收到对应事件邮件（规则核对表）
