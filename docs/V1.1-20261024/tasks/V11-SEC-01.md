# V11-SEC-01：XSS 净化器不闭合标签放行修复

## 归属

## 目标

## 输入

## Execution Steps
1. [ ] 写复现单测：<img onerror=alert(1)>、<img src=x onerror、<svg onload= 等不闭合/畸形输入进入 sanitizeRichContent
2. [ ] 定位放行原因（容错解析分支）并修复：畸形标签按白名单解析器整体拒绝或强制闭合后再过滤
3. [ ] 回归文章/服务/课程详情渲染（共用净化入口），确认合法内容不受影响
4. [ ] 证据含修复前后行为对照

## 验收标准
- [ ] 畸形不闭合标签经净化后不含事件属性/脚本向量（单测断言）
- [ ] 既有合法富文本渲染不回归（既有净化单测全绿 + 详情页冒烟）
- [ ] 净化入口唯一：三个详情页走同一函数（grep 证实无旁路）
