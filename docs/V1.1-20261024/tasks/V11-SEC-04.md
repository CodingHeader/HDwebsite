## Execution Steps
1. [ ] chat：首次访问由服务端签发 httpOnly 会话 cookie（签名 sessionId），请求校验签名，替代裸信 body.sessionId；历史读写按会话隔离
2. [ ] 采集 fetch 前 DNS 解析并校验目标 IP 非私网/环回/链路本地（含重定向后复检或禁跟随跨源重定向）
3. [ ] 单测：伪造他人 sessionId 取不到历史；采集 http://169.254.169.254/ 127.0.0.1/10.x 被拒

## 验收标准
- [ ] 未签名/他人 sessionId 无法读写会话
- [ ] SSRF 目标黑名单生效（单测）
- [ ] 正常 chat/采集流程不回归（e2e 冒烟）
