## 2. 媒体资产模型（Media 表）

| 字段 | 说明 |
| --- | --- |
| filename / path / url / mimeType / size | 基础信息 |
| type | image / video / document（预留） |
| category | banner / article / avatar / upload… |
| uploaderId | 归属上传者 |
| metadata JSON | {width,height,duration, thumb, small, medium} |

- 管理：`/manager/media` 媒体库页面 + `/api/media` CRUD + `/api/upload` 上传。
- 消费：ImageUploader/ImageField 组件回填 url；文章/课程/证书等以 URL 字符串引用。

## 3. 资源流水线

```
上传/生成
  → upload-service 校验落盘（uploads/yyyymm + thumbs 三级缩略图）
  → Media 入库
  → /uploads rewrite → /api/file 读取
  → 前台 <img>/next-image 引用
```

- 图标体系：Lucide React 图标名存储于 DB（HomeCard.icon / ManagerMenu.icon / ServiceGuide.icon / HotMajor.iconType），组件内映射渲染；自定义图片走 iconImage。

## 5. 重构期资源规划（新增功能）

| 资源 | 规划 |
| --- | --- |
| 公众号素材 | 公众号图文内图片经 upload-service 统一落盘，发布前转微信素材（media_id），映射存 WechatAsset 表 |
| 采集图片 | 采集正文图片可配置"转存本地/直链"（默认转存，防防盗链失效） |
| 知识库文件 | md/txt/docx 导入文件存 uploads/knowledge/，解析后正文入库、原件保留 |
| 邮件资源 | 邮件模板图片引用站内 URL（需绝对域名，读 APP_DOMAIN） |
| 资源清理 | 媒体库增加"未被引用检测"（扫描各表 URL 字段），防孤儿文件膨胀 |
