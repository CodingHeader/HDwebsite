## 通过标准

- 里程碑验收 = 该节全部验证项通过 + 证据留存完成（缺证据视为未通过）
- 部分依赖外部凭证的项可标记 `deferred(凭证)`，但不影响其余项；里程碑整体通过需补齐后复核
- 自 M1 起：验收默认包含自动 UI 走查（工具按用例自动执行、逐步截图存 evidence/screenshots/；Q7 轮产品所有者选定），人工走查项可并行保留
- G5 基础目标门（Q9 轮产品所有者选定）：BG1~BG5 每里程碑逐条核验，任一不达标视为该里程碑未通过

## 用例记录格式（验证执行时使用）

| 字段 | 说明 |
| --- | --- |
| 用例 ID | 沿用本表编号（如 M1-6） |
| 前置条件 | 环境/数据/凭证要求（含 deferred 标记） |
| 步骤 | 可复现操作序列 |
| 预期 | 可判定结果 |
| 结果 | pass / fail / deferred(原因) |
| 证据 | 文件相对路径（screenshots/logs/核对面单） |

## 证据目录规范

```
06_validation/evidence/
  EVD-M1-001/            # 每次验证执行一个目录，三位递增
    checklist.md         # 用例 ID × 结果 × 备注 × 证据路径
    screenshots/         # 截图（命名含用例 ID，如 M1-2-markdown.png）
    logs/                # 日志摘录
```

- checklist.md 须引用本计划用例 ID；fail 用例必须记录原因并登记跟进任务（05_execution/tasks/）
- EVD 目录不删除、不覆盖；复验另开新目录（递增编号）
