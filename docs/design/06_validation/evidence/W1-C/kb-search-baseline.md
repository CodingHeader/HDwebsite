## 2. fixture 来源与构造说明

- 文件：`src/lib/__tests__/lane-c/fixtures/kb-qa.json`（**20 条**中文问答，`{id, question, expectTitle}`）。
- 选题来源：官网继续教育场景的**高频咨询主题**（报名材料、学费、专升本专业、联系方式、上课时间、学位发放、退费、考试难度、函授/业余区别、学历承认、报名截止、入学考试、校区地址、在职就读、学费分期、网络教育、补考重修、转专业、学信网、毕业论文）——覆盖咨询/收费/教务/证书四类。
- 语料构造（`kb-search.test.ts`）：每条问答生成 **2 篇文档**
  - **正解文档**：标题 = `expectTitle`，正文为泛化说明（**不含问题原词**）
  - **干扰文档**：标题为「常见问题汇总 N」，正文**逐字重复问题原词 3 次**
- **基线暴露的弱点**：旧口径不含标题加权，干扰文档因正文重复原词而得分偏高，把正解挤出 Top-3 → 基线仅 50%。
- **新算法的收益来源**：标题命中权重 ×3 → 标题即答案的正解文档上浮；同时 bigram 连续计分与归一化抑制「重复原词」的长文虚高。
