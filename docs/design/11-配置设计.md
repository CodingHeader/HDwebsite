## 1. 环境变量（.env）

| 变量 | 当前值 | 说明 |
| --- | --- | --- |
| DATABASE_URL | `file:./dev.db`（运行时由 start-next.mjs 注入 `file:./prisma/dev.db`） | SQLite 路径 |
| JWT_SECRET | `xgnedu-jwt-secret-key-2026-hdwebsite` | JWT 签名（缺失启动即抛 FATAL；≥32 字符） |
| PORT | 6789 | 服务端口（dev 固定 6789；生产可覆盖） |
| APP_DOMAIN | `www.hd1994.com` | 站点域名 |

> 注意：Prisma 7 不自动加载 .env，须在 prisma.config.ts 显式引入 dotenv —— 已落地。

## 4. 应用配置体系（Setting + Registry）

### 4.1 存储
- Setting 表：key 唯一 / value / type(string·number·boolean·json) / group / isPublic / isEncrypted。

### 4.2 Registry 分组（settings-registry.ts）
| 分组 key | 内容 |
| --- | --- |
| site | 站点名称/Logo/品牌 |
| topbar | 顶部通知文案、联系电话 |
| banner | 首页轮播背景/文字/位置 |
| stats | 统计横幅数据 |
| company | 简介/标语/视频 |
| contact | 电话/邮箱/地址/微信/QQ |
| seo | 全站 SEO |
| cards | 四宫格卡片文案 |
| footer | 页脚配置 |

- 类型控件：text/textarea/number/url/image/email/phone/boolean/json/color/select；支持 colSpan、required、zod 校验、options。
- `isPublic=true` 的项可被前台 useSettings 读取；敏感项 isEncrypted。

### 4.3 AI 配置（AIConfig 表级配置）
endpoint / apiKey / model / temperature / maxTokens / rateLimit(60/min) / dailyQuota(1000) / allowedDomains / systemPrompt / greeting / isActive。

### 7.2 /api/settings 行为与 Registry 工具族（实测）
- GET 公开（DB isPublic ⊕ Registry 默认）；POST 登录即可（**无 setting:edit 权限点**，安全缺口）→ validateSettings 批量校验 → 按元数据 upsert。
- Registry 工具族：getRegistry / getGroups / getSettingsByGroup / getSettingDefinition / getDefaultValues / validateSetting(s) / getPublicSettingKeys。
- 新功能配置项（email / wechat-mp / collect / llm / notify 分组）一律在 SETTINGS_REGISTRY 注册，动态表单自动生成。
