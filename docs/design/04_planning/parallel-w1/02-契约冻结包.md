## ① API

现有约定保持：信封 `{code, data, message}`；分页 `{list, pagination:{page,limit,total,totalPages}}`；`listQuerySchema` 的 page/limit(≤100)/keyword；时间 ISO 8601；字段 camelCase；ID 为正整数。

| code | HTTP | 场景 | 错误体 | 前端展示（managerFetch / ChatWidget） |
| --- | --- | --- | --- | --- |
| 200 | 200 / 201(created) | 成功 | `data` 为结果 | 成功 toast（toastCopy） |
| 400 | 400 | zod 校验失败、业务规则拒绝（含知识库 PDF/图片） | `data: { fieldErrors: Record<string,string> }` 或 `null` | 字段 aria-invalid + 首条 message toast |
| 401 | 401 | 未登录/令牌过期 | `null` | 跳转 /manager/login |
| 403 | 403 | 无权限（含非超管开启 autoApprove） | `null` | Forbidden 视图 / toast |
| 404 | 404 | 资源不存在 | `null` | Empty/Error 视图 |
| 409 | 409 | 唯一约束冲突（Prisma P2002） | `null` | toastCopy.conflict |
| 429 | 429 | AI 咨询限频（每 IP 每分钟 10 次） | `null` | ChatWidget 提示“太频繁” |
| 500 | 500 | 未捕获异常（不泄漏堆栈；触发 system_error 邮件） | `null` | toastCopy.failed |
| 502 | 502 | 上游失败（LLM/微信/采集源） | `null` | toastCopy.badGateway |
| 503 | 503 | 全部模型额度/限频用尽 | `null` | toastCopy.serviceUnavailable |

决定（ADR-028）：保留 `data.fieldErrors`（K9 → 待用户确认 D6）；`created()` 维持 code 200/HTTP 201（K10 → D7）；`ApiHttpError` 可抛 400/401/403/404/409/429/502/503。**非 JSON 例外**（登记在 `tests/contract/rules.ts` 的 `NON_JSON_ROUTES`）：`/api/file/[...path]`（文件流）、`/api/wechat/callback`（XML/echostr）、`/api/health`（探活，可保持 JSON）、`/api/chat/stream` 的成功流体（SSE；失败仍为 JSON 信封）。

## ③ Identity（不变 + 明确越权禁止）

- 用户 ID：Int；角色：SuperAdmin / Editor / Viewer（Role.isSuper）；JWT claims `{uid, username, roleId, isSuper, permissions[]}`；权限点 `module:action`（catalog 见 contracts/auth.ts）。
- 本轮新增权限点：无（kb:*、block:*、notify:* 已存在于 catalog 与 seed）。
- 明确禁止的越权路径（每条在 W2-02 契约测试或卡内单测中有用例）：
  1. 非超管把 content-items 改为 approved/published（400）或调用 `/review`（403）。
  2. 非超管开启 collectSource.autoApprove（403）。
  3. 无 kb:create 上传、无 kb:delete 删除知识库文件（403）（沿用 contracts/auth.ts:79 的 list/create/edit/delete 四动作）；无 block:edit 调 `/api/home-blocks/reset`（403）。
  4. 未登录可调用的写接口白名单：`/api/apply`、`/api/chat/stream`、`/api/user-actions`（访客），`/api/auth/login`、`/api/auth/refresh`、`/api/auth/logout`（认证流程），`/api/wechat/callback`（微信服务器回调，以签名校验代替登录）；其余写操作一律 401。
  5. Setting 中 secret 键（含新增 kbCozeSpaceId）任何接口只返回脱敏值。
