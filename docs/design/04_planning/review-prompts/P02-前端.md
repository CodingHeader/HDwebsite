## 目标
1. 前台恢复为 main 原有的**红色横幅轮播**风格（品牌红令牌 `--primary: #da251d`、TopBanner + Banner 轮播、11 个区块、多级下拉导航）。同一份数据下，upgrade 前台 15 个路由在 1440/768/375 宽度的截图与 main 的像素差 ≤1%（`npm run test:visual` 通过）。

## 管理端设计系统（本方向落令牌与外壳，P07 落组件；整个 /manager 必须遵守）
- **作用域**：所有管理端令牌只定义在 `[data-theme="manager"]`（`src/app/manager/layout.tsx` 根节点设置），前台 `:root` 令牌保持 main 原值。
- **色彩**：中性灰阶为底（`--mgr-bg: oklch(0.985 0 0)`、`--mgr-surface: #fff`、`--mgr-border: oklch(0.922 0 0)`、`--mgr-muted-fg: oklch(0.556 0 0)`）；强调色 = main 品牌红 `--mgr-primary: oklch(0.505 0.213 27.5)`（brand-600）、hover brand-700；语义色 success `oklch(0.627 0.17 149)`、warning `oklch(0.769 0.165 70)`、danger `oklch(0.577 0.245 27.3)`、info `oklch(0.588 0.158 241)`；文字对比度 ≥ 4.5:1。
- **字体与排版**：沿用 main 的 Geist（无则系统中文栈 PingFang SC/Microsoft YaHei）；字号阶 12/13/14(正文)/16/20/24/30；行高 1.5；数字使用 `tabular-nums`。
- **间距/圆角/阴影**：4px 栅格（4/8/12/16/24/32）；圆角 6（控件）/10（卡片）/14（对话框）；阴影两级（`sm` 卡片、`lg` 浮层）。
- **密度**：表格行高 44（舒适）/36（紧凑），用户可在用户菜单切换并持久化。
- **外壳布局**：左侧 Sidebar 240px（可折叠为 64px 图标栏，分组标题 + 当前项高亮 + 徽标计数位），顶栏 56px（面包屑 + 全局搜索/命令面板 `Ctrl/⌘+K` + 通知入口 + 用户菜单），内容区最大宽 1440px、页边距 24px；`<lg` 断点 Sidebar 变为左侧抽屉（Sheet），顶栏显示菜单按钮。
- **图标**：lucide 按名称显式导入的映射表（`MenuIcon.tsx`），禁止 `import * as Lucide`。
- **可访问性**：所有交互元素可键盘到达、焦点环 `ring-2 ring-[--mgr-primary]/40`、对话框焦点陷阱、`aria-current` 标注当前菜单。
- **页面骨架（P05/P07 必须使用）**：`PageHeader`（标题+描述+主操作）→ 筛选栏 → 内容（DataTable/表单/卡片）→ 分页；五态组件统一。
