## 目标
1. 管理端：所有页面五态齐备（Skeleton/EmptyState/ErrorState+重试/Forbidden/Toast），零 `window.confirm|alert(`，危险操作用 ConfirmDialog。
2. 前台：`/apply` 恢复 main 的 AI 咨询交互（视觉为 main 原有红色风格）（数据来自 ChatScene `apply`，调用 upgrade 的 `/api/chat/stream`），视觉与 main 截图一致。
3. Playwright E2E 覆盖：登录 → 文章新建/编辑/删除 → 采集源试抓 → 审核通过 → 建发布任务 → 通知记录出现；访客 /apply 发送消息收到流式回复（mock 供应商）。
