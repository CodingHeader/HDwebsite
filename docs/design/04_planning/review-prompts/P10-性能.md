## 目标（相对 P02 后重测基线）
- `/manager` JS gzip 降低 ≥ 40%（依据：后台首屏需下载并解析全部脚本，包体直接影响可交互时间）。
- `npm start`（已构建、源码未变）到 Ready ≤ 10s（依据：重启停机时长 = 用户不可用时间）。
- 首页热 TTFB 不劣化；冷启动后第二次请求起命中缓存（内容变更后 ≤ 5s 内可见）；P06 接入的首页区块配置读取（ADR-024）不得增加每请求查询次数（随首页数据一并缓存，区块配置变更后同样 ≤5s 可见）。
