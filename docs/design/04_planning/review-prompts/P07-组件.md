## 目标
`src/components/ui/**`（基础件）+ `src/components/manager/**`（业务件）构成完整设计系统；/manager 下 100% 页面只使用这些组件；TipTap 富文本恢复且输出经统一净化；新增通知规则页与菜单。

## 组件清单（实现规格，全部遵守 P02 令牌、作用域 `[data-theme="manager"]`）
**基础件 `src/components/ui/`**（base-ui/shadcn base-nova 风格，从 main `src/components/ui/**` 移植后补齐）：Button（primary/secondary/outline/ghost/danger，sm/md/lg，loading）、IconButton、Input、Textarea、Select、Combobox（可搜索，异步加载）、Checkbox、Switch、RadioGroup、DatePicker/DateTimePicker（原生 input[type=datetime-local] 封装，不新增依赖）、Label、FormField（label/描述/错误/必填标记）、Dialog、Sheet（侧滑抽屉）、DropdownMenu、Tooltip、Popover、Tabs、Badge、Avatar、Card、Separator、ScrollArea、Skeleton、Table 原语、Pagination、Kbd。
**业务件 `src/components/manager/`**：
- `PageHeader`（标题、描述、面包屑由 shell 提供、主次操作区）
- `DataTable`（列定义：排序、格式化 render：text/image/badge/boolean/date/relative-time/money/link；工具栏：关键词搜索 300ms 防抖、筛选器 chips、列显隐、密度切换、刷新；行选择 + 批量操作栏；行操作 DropdownMenu；空/加载/错误态接 P05 feedback；分页：总数 + 每页 10/20/50/100 + 页码省略号；URL 同步 `?page&limit&keyword&sort&filters`）
- `ResourceForm`（由字段规格渲染；分区 `sections` + 折叠"高级设置"；字段级错误映射后端 400 message；未保存离开提示；Ctrl/⌘+S 保存）
- 字段件：`RichTextField`（TipTap：标题/加粗/斜体/下划线/列表/对齐/链接/图片-走媒体库，提交前 `sanitizeRichContent`）、`MarkdownField`（编辑/预览分栏，预览用 `MarkdownRenderer`）、`ImageField` + `MediaPicker`（媒体库对话框，支持上传/搜索/选择）、`TagsField`、`RelationSelect`（Combobox 远程搜索）、`JsonField`（校验）、`SecretField`（脱敏回显、"已设置"状态、替换）
- `StatCard`、`StatusBadge`（统一状态色：draft/pending/approved/published/failed/cancelled/active/inactive）、`DetailDrawer`（只读详情，logs/chat-history 用）、`ConfirmDialog`（P05 已有，危险操作需输入名称确认可选）
- `CrudPage` 重写为 `PageHeader + DataTable + ResourceForm(Dialog 或 Sheet)` 组合，保留现有 `CrudPageSpec` 接口向后兼容
