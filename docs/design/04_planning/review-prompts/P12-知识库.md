## 目标
1. 新增 KnowledgeBase / KnowledgeFile 实体，Knowledge 归属库；上传 md/txt/html 文件 → 解析 → 按标题/段落切分（≤800 字/块，重叠 100 字）→ 生成条目。
2. 本地检索改为：按库过滤 → 中文二元分词（bigram）+ 关键词 + 标题加权的 BM25 风格打分（纯 TS 实现，无新依赖），在 SQLite 侧先用 `LIKE` 预筛候选 ≤ 500。
3. ChatScene 绑定：`knowledgeBaseIds[]`、`providerIds[]`（场景内优先级，空则走全局 default→priority→fallback）、`systemPrompt`、`temperature/maxTokens/topP` 覆盖；chat-service 两渠道共用。
4. 采集源可指定目标库（默认"采集资讯"库，seed 创建）。
