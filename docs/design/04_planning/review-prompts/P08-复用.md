## 目标
1. `src/contracts/resources.ts` 成为资源的唯一源：zod schema 上以 `.meta()`（zod 4）或并列 `resourceMeta` 描述 label/表单控件/列展示；`crud-specs` 与后端 `crud-resources` 的字段级信息由其派生，手写部分只剩"特殊行为"（行操作、钩子）。
2. JSON 字段、外呼 HTTP、设置读取、路由样板各收敛为一个模块。

## 输入
- 文档：08-复用设计.md
- 契约：`src/contracts/**`（本方向会修改 resources.ts 结构，**不改**字段语义）
- 前置任务：P07（组件 API 稳定）
- 前置状态：E2E/视觉门禁可运行

## 输出（新增/修改文件）
- `src/contracts/resources.ts`：为每个资源补 `meta`（label、widget、column、section、order）；统一 `statusEnum` 常量并导出
- `src/contracts/derive.ts`（新）：`deriveFormFields(schema)`、`deriveColumns(schema)`、`deriveFilters(schema)`
- `src/components/manager/crud-specs.tsx`：改为调用 derive + 少量覆盖（目标 ≤ 200 行）；P06/P07 新增的 blocks 资源（`src/contracts/blocks.ts`）一并纳入派生
- `src/lib/crud-resources.ts`：去除与契约重复的字段列表，仅保留模型名/权限/钩子
- `src/lib/json-field.ts`（新）：`encodeJsonFields/decodeJsonFields`（含幂等），替换零散 JSON.parse/stringify
- `src/lib/http-client.ts`（新）：`httpFetch(url, { timeoutMs, retries, ua, logTag })`，替换 15 处外呼
- `src/lib/settings.ts`：明确 `getPublicSettings()`（前台）/`getAllSettings()`（服务端内部），旧名保留 re-export 一版并标 `@deprecated`
- 剩余路由迁移到 `withApi`；清理过期注释
- `src/contracts/__tests__/derive.test.ts`：每个资源派生结果快照 + "契约字段 ⊆ 表单字段（排除 readOnly）"断言
