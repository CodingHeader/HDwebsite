## 目标
1. 契约②冻结：code 枚举 = {200, 400, 401, 403, 404, 409, 429, 500, 502, 503}，HTTP 状态与 code 一致；错误体 `{code, data:null, message, details?}`（details 仅 400 字段错误列表）；非 JSON 例外路由白名单（wechat/callback、file、chat/stream 的流体、robots/sitemap）。
2. SSE 事件以 zod 判别联合定义并由服务端/ChatWidget 共用。
3. 自动生成的全路由契约测试（含 P06 的 blocks 四资源与 P12 的知识库/文件端点；知识库上传对 PDF/图片返回 400 的用例必须在列）：遍历 `src/app/api/**/route.ts` 导出的方法，按规则构造请求（未登录、非法参数、合法参数），断言信封与状态码。
4. 管理端 375/768/1440 三宽度 Playwright 截图与"无横向溢出"断言通过。
