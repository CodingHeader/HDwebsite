## 2. 项目速览（30 秒版）

- **系统**：学历提升机构官网 + 后台管理 + AI 智能咨询（www.hd1994.com）。
- **技术栈**：Next.js 16 App Router / React 19 / TS strict / Tailwind v4 + shadcn / Prisma 7 + SQLite / JWT + RBAC / TipTap / sharp / zustand / zod。
- **前台**：首页、学校概况、招生专业、招生院校、新闻文章、证书、校区、在线报名、服务指南等 13 类页面。
- **后台**：25 个管理页（另含 login），ManagerMenu 表驱动，RBAC 三角色。
- **AI**：OpenAI 兼容代理（Modelscope）+ 场景差异化（ChatScene）+ 知识检索（Knowledge tags contains）。
- **部署**：宝塔 80 反代 → standalone:6789；docker-compose 可选；SQLite 挂载持久化。
