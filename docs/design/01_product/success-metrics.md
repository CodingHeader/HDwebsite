# Success Metrics（成功指标草案）

> ⚠️ **状态：draft，待产品所有者确认。** 数值为建议基线，确认后转 active 并作为 M1~M4 验收参照。

## 1. 获客与转化（G1）

| 指标 | 基线建议 | 采集方式 |
| --- | --- | --- |
| 月报名线索量 | 现状值 +20%（重构后 3 个月） | Student 表计数（后台仪表盘） |
| AI 咨询会话 → 报名转化率 | ≥5% | AIChatHistory 会话与 Student 关联（需埋点接线，见 ASM-008） |
| 悬浮咨询点击量 | 周环比不下降 | UserAction（依赖埋点决策） |

## 2. 内容运营效率（G2/G4）

| 指标 | 基线建议 | 采集方式 |
| --- | --- | --- |
| 政策/新闻发布耗时 | 从人工搜集+排版 ≥30 分钟 → ≤10 分钟 | 采集→审核→发布链路计时（CollectTask/PublishJob 时间戳） |
| 公众号发文频率 | 稳定每周 ≥2 篇 | ContentChannel 发布记录 |
| 人工排版工作量 | Markdown 一键发布，排版工时 → 0 | 定性验收 |

## 3. 智能服务质量（G3）

| 指标 | 基线建议 | 采集方式 |
| --- | --- | --- |
| AI 咨询可用率 | ≥99%（月度，含兜底模型生效） | llm-gateway 调用成败统计 |
| 模型故障降级生效 | 主模型失败 → 备用应答 ≤30s | 网关路由日志 |
| 知识库命中率 | 检索测试命中相关 chunk ≥80% | 知识库"检索测试"工具抽样 |

## 4. 系统可靠性（非功能）

| 指标 | 基线建议 | 采集方式 |
| --- | --- | --- |
| 页面响应 | 列表/详情 P95 ≤500ms（服务端渲染） | 部署后抽样压测 |
| 提醒触达 | 余额/报错提醒发出 ≤5 分钟 | NotifyRecord |
| 数据安全 | 零凭据明文入库；每日备份成功留存 ≥14 份 | 定期巡检 + backup 任务记录 |

## 5. 度量基建依赖

- 埋点走向已定（Q7 轮，2026-10-11）：UserAction 最小接通（表单提交 + 关键页浏览），§1 转化类指标可自动统计（ASM-008）。
- 目标值确认时点已定：M1 验收时逐项确认（Q7 轮），确认后本文件转 active。
- 指标看板建议随 M3 落地进后台仪表盘（不单独建 BI）。
