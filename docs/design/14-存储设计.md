## 2. 文件存储（本地落盘）

### 2.1 目录规则
```
public/
├── uploads/            # 用户上传根（uploadDir）
│   └── yyyymm/         # 按月子目录（dateSubDir）
│       ├── {timestamp}-{rand6}.jpg   # 原图（安全文件名）
│       └── thumbs/
│           ├── {stem}-thumb.jpg    # 100×100 q80
│           ├── {stem}-small.jpg    # 300×200 q85
│           └── {stem}-medium.jpg   # 800×600 q90
└── images/seed/...     # 种子/静态资源（另有 seo/、videos/ 约定）
```

### 2.2 访问链路
```
浏览器 → /uploads/yyyymm/x.jpg
  → rewrite → /api/file/yyyymm/x.jpg   # API 读取（standalone 兼容）
Media 表记录 path(相对 public) / url / metadata(缩略图 URL)
```

### 2.3 约束
- 类型：jpeg/png/gif/webp；大小 ≤5MB；扩展名白名单。
- 仅图片（type=image）；video/document 类型在 Media 模型预留未启用。

## 4. 持久化与备份

| 机制 | 说明 |
| --- | --- |
| Docker volume | `./prisma:/app/prisma` —— 容器重建数据不丢 |
| 宝塔部署 | 数据库随站点目录落盘 |
| 备份现状 | 手工 .sql/.bak；无自动备份 → 重构期建议：每日定时备份 dev.db + uploads（tar 归档，保留 N 份） |

## 5. 存储风险与重构决策

| # | 项 | 决策 |
| --- | --- | --- |
| S1 | 上传存 public 与 standalone 同步耦合（start-next 需同步目录） | 中期迁独立 uploads 目录 + /api/file 直读；远期 OSS 可插拔（upload-service 单点已具备收敛条件） |
| S2 | api/appSecret 明文入库 | 统一 isEncrypted 字段 + AES 加解密工具，密钥走环境变量 |
| S3 | 无自动备份 | 调度基座加 backup 任务（见 16 章） |
| S4 | 采集内容存储位置 | 采集原文存 CollectItem，审核通过后生成 KnowledgeFile（正文入 DB）；大文件（>1MB）存文件系统，DB 存引用 |
| S5 | SQLite → PG 迁移预留 | Prisma datasource 可切换；避免使用 SQLite 特有 SQL |

## 6. 补充（2026-10-10 第二轮实测）：public/ 实际目录结构

```
public/
├── favicon 全套：favicon.png / favicon-16x16 / favicon-32x32 / favicon-48x48
│                android-chrome-192x192.png / android-chrome-512x512.png / apple-touch-icon.png
├── site.webmanifest
├── images/
│   ├── logo.png / logo_card.png / logo-icon-only.png / logo_xgnedu.png
│   ├── campus/            # 校区图
│   ├── gallery/           # 证书/风采图
│   ├── seed/              # 种子图（banner-1~3.svg 等）
│   ├── xgnedu/            # 自 xgnedu.cn 抓取素材
│   └── xgnedu-manifest.json  # 抓取清单
├── seo/                   # OG 图等 SEO 资源
├── videos/                # 视频资源（预留）
└── uploads/               # 运行期上传落盘（含 banners/、yyyymm/、thumbs/）
```

> 根目录另有 logo.png / logo_card.png 副本（历史遗留，与 images/ 重复）——重构期收敛为单一位置；Registry siteLogo/siteLogoIcon 默认值已指向 /images/ 路径。
