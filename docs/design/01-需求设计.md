## 4. 角色与权限需求（As-Is）

| 角色 | slug | 能力 |
| --- | --- | --- |
| SuperAdmin | super-admin | `isSuper=true`，全部权限 |
| Editor | editor | 内容管理（文章/分类/标签等，按 permissions JSON） |

- 默认账号：`admin / admin123`（seed 注入）。
- 权限格式：`module:action`（如 `article:create`），支持 `module:*` 与全局 `*` 通配。

## 5. AI 智能咨询需求（As-Is）

1. 管理端配置大模型（OpenAI 兼容端点，当前对接 Modelscope）：endpoint / apiKey / model / temperature / maxTokens / systemPrompt / greeting。
2. 多场景入口（ChatScene）：报名页全面咨询、悬浮咨询、政策解答等，各场景独立：欢迎语、系统提示词、知识 tag 白名单、页面文案（标题/副标题/流程步骤/服务承诺）。（注：快捷提问 starters 仅后台可配置，前台 apply 页未渲染——死字段）
3. 知识检索：按场景 `knowledgeTags` 检索 Knowledge 表，priority 降序取 6 条注入 system；场景可关闭知识库（`useKnowledgeBase`）提速。
4. API Key 不落浏览器：前台一律走 `/api/chat/completion` 服务端代理。
5. 会话留存：AIChatHistory（sessionId/conversationId/ip/ua/tokens/耗时/页面）。
