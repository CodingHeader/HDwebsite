# REQ-C-002：微信公众号平台约束

## 1. 约束内容（外部不可协商项）

| 约束 | 值 | 影响 |
| --- | --- | --- |
| 被动回复时限 | 5 秒内必须应答 | REQ-F-009 采用"快速应答 + 客服消息异步补发" |
| 客服消息窗口 | 48 小时内可主动下发 | 长答案补发窗口；过期仅能等用户再发消息 |
| API 调用 IP 白名单 | 服务器出口 IP 须在公众平台配置 | DEP-001 联调前置；服务器 IP 变更需同步 |
| 认证服务号 | 素材/草稿/客服接口仅认证服务号可用 | ASM-002 假设运营方完成认证；订阅号功能受限 |
| access_token | 有效期 7200s，每日获取上限 2000 次 | token 缓存策略（过期前 5 分钟刷新） |
| 草稿/发布 | draft/add 单次 1 篇；freepublish 有平台频控 | 发布频控 ≥60s、每日默认 20 篇上限 |
| 图文内容 | 外链图片会被替换/过滤（需转永久素材或微信域） | 正文图片上传替换流程 |
| 每日群发 | 认证服务号 4 次/月（模板/客服消息不受限） | 群发不在本期范围 |

## 2. 依据

微信公众平台官方接口文档（被动回复/客服消息/草稿箱/发布能力）。

## 3. 风险关联

RISK-002（平台政策变动：接口下线、频控收紧需跟进适配）。
