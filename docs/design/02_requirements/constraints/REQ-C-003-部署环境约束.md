# REQ-C-003：部署环境约束

## 1. 约束内容

| 约束 | 值 |
| --- | --- |
| 形态 | 单台云服务器（宝塔面板），无容器/无编排 |
| 运行 | PM2 托管 Node standalone 进程（1 实例） |
| 域名 | www.hd1994.com + SSL（现状保留），微信回调路径可公网访问 |
| 出口 IP | 须固定（微信 API 白名单依赖，DEP-006） |
| 数据库 | SQLite 本地文件 + 备份目录，无独立 DB 服务 |
| 资源 | 单机配置有限：采集/AI/发布任务错峰（夜间窗口），避免峰值叠加 |
| 人工运维 | 运营/管理员非开发人员：一切配置后台化（ADR-003/004 的动因） |

## 2. 设计含义

- 不引入 Redis/消息队列：任务队列用 SQLite 表 + 进程内调度循环实现（轮询留痕）
- 不引入独立 worker：调度、采集、发布随 Next 进程运行
- Docker 不在范围（REQ-C-001 锁定部署形态）
