# REQ-INBOX-20261010-001：重构与新增设计需求

## 1. 原始描述（用户原话，未改写）

> 我计划重构本项目，希望从需求、前端、后端、数据、交互、逻辑、组件、复用、拓展、性能、配置、知识库、响应、存储、资源等等方面全方位进行提取设计数据。
> 希望你提取到 "docs/get/" 目录下，分门别类，结构清晰，本次任务禁止编辑和新建其他目录文件。使用标准的 markdown 格式。
> 你还需要将我们的每一次对话 QA 保存为 `docs/get/talk.md`，不要改变原意，递增保存。
> 以最新设计为准，如果存在拿不准的冲突，你可以和我进行多轮讨论，直到达成 100% 置信度。
> 并且新增一些设计。

### 新增设计（11 项）

1. 官网和官方公众号统一管理。
2. 自定义自动采集各大学校、部门的政策、新闻。
3. 自动更新和发布官网信息和新闻。
4. 官网的信息发布可使用 markdown 格式，自动转成网页。
5. 自动发布公众号文章。
6. 采集的信息、新闻默认作为知识库文件。
7. 知识库管理。知识库模型管理、知识库中的文件管理、其他管理。
8. 配置和使用大模型，大模型可以使用知识库、配置提示词及其他参数。
9. 允许配置官网和公众号的 AI 客服。
10. 大模型需要配置多个模型，设置对话优先级，并配置默认和兜底模型。
11. 邮箱提醒功能。支持对多人进行提醒，发布新闻前提醒、发布信息前提醒、发布公众号文章前提醒、大模型余额不足提醒、报错提醒。

## 2. 背景

现有系统为克隆自 xgnedu.cn 模板的教育官网（弘道教育，www.hd1994.com），具备前台/后台/AI 咨询三层，但内容运营（官网+公众号）依赖人工、知识库单表扁平、大模型单供应商、无自动化与提醒能力，需系统性重构升级。
