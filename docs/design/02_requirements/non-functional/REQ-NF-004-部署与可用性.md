# REQ-NF-004：部署与可用性

## 1. 基本信息

| 项 | 值 |
| --- | --- |
| 类型 / 状态 | non-functional / approved |
| 适用范围 | 构建、部署、运维 |

## 2. 目标

保持现状部署体验（宝塔 PM2 一键部署），新增自动化能力（调度/采集）随应用进程运行，单机故障可快速恢复。

## 3. 需求描述

| 项 | 要求 |
| --- | --- |
| 构建 | `npm run build` 成功产物 standalone 输出，BUILD_ID 同步现状机制保留（TN-001） |
| 部署 | 宝塔 PM2 单进程；调度循环随进程内启动（不引入独立 worker 进程），宕机重启自动恢复（ASM-006 停机窗口） |
| 数据 | 迁移脚本幂等可重跑；备份策略沿用宝塔定时（每日），备份含 SQLite 文件 + uploads |
| 可用性 | 目标 99% 月可用（单机非集群，ASM-001 低并发前提下）；故障恢复 RTO ≤1h（重启+备份回滚） |
| 监控 | 无 APM 前提下：系统报错邮件（REQ-F-011）+ PM2 日志巡检；模型/任务失败可追溯（留痕模型） |
| 环境 | Node ≥ 现状约定（standalone 运行时）、DATABASE_URL 注入保留 |

## 4. 验收条件

- [ ] 全新服务器按部署文档 30 分钟内可恢复服务（含数据恢复）
- [x] PM2 重启后调度任务自动恢复执行（无需人工触发）（证据：src/lib/__tests__/scheduler-cron.test.ts）
- [ ] 备份恢复演练 1 次通过
- [ ] 重构期间保持线上服务连续（灰度切换，非停机重建）
