# REQ-NF-001：性能与响应

## 1. 基本信息

| 项 | 值 |
| --- | --- |
| 类型 / 状态 | non-functional / approved |
| 适用范围 | 前台页面、AI 接口、后台管理、调度任务 |

## 2. 目标

重构后前台关键路径不劣于现状，新增自动化能力不拖垮单机 SQLite 并发。

## 3. 指标（验收口径）

| 指标 | 预算 | 现状参考 |
| --- | --- | --- |
| 前台首屏 LCP（站点首页） | ≤2.5s（3G Fast） | P1 基线（10-性能 §2） |
| 前台动态页 TTFB | ≤500ms | 站点端 SSG 化承诺 |
| 后台列表页响应 | ≤1s（分页 ≤50 条） | — |
| AI 非流式回复 | ≤30s（网关超时口径），流式首 token ≤3s | 现状 88s 宽限收敛 |
| 知识检索注入 | ≤6 chunk、注入量维持现状 token 量级 | take 6 现状 |
| 采集任务 | 每源 ≥2s 限速、批次超时 30min、并发 1 源 | 新增 |
| 调度循环 | 每分钟 1 次扫描，空转开销 <10ms DB 查询 | 新增 |
| SQLite 写并发 | 事务内单写者，写操作 ≤100ms 级；超时 5s 让步重试 | RISK-007 应对 |

## 4. 验收条件

- [ ] Lighthouse 移动端 Performance ≥ 现状基线（对照 10-性能 §2 记录）
- [ ] 网关超时 30s 生效（可配），不再出现 88s 空等
- [ ] 采集限速与批次超时生效
- [ ] 发布/入库高峰（每分钟 ≤5 写任务）无 SQLite BUSY 报错
