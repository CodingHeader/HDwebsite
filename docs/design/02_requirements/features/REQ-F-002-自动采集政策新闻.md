# REQ-F-002：自定义自动采集各大学校、部门的政策、新闻

## 1. 基本信息

| 项 | 值 |
| --- | --- |
| 类型 / 状态 | functional / approved |
| 来源 Inbox | REQ-INBOX-20261010-001（新增设计第 2 条） |
| 对应原编号 | N2 |
| 优先级 | P1（M3） |

## 2. 背景

各省院校/教育部门的政策（自考/成考/开放大学）是招生的关键咨询素材，目前全靠人工搜集，时效差、遗漏多，且无法沉淀为知识库供给 AI 咨询。

## 3. 目标

按可配置采集源自动、定时抓取目标院校/部门网站的政策与新闻，去重后进入审核队列，供发布与知识库复用。

### 用户故事

作为运营，我想把目标院校/部门的政策页配成采集源并每日自动抓取，以便不再人工逐站搜集素材。

## 4. 需求描述

采集源（CollectSource）支持类型 rss/html，配置解析规则（listSelector/titleSelector/contentSelector 等）、调度 cron（默认每日 1 次、凌晨执行，管理端可改，Q10 轮定）、目标知识库与自动标签；调度基座创建采集任务（CollectTask）执行抓取；条目（CollectItem）以 urlHash 主去重 + 标题相似度（0.9）辅助去重；后台提供采集源管理与采集条目审核队列（通过/拒绝/编辑后入库）。

## 5. 范围

### In Scope

- CollectSource / CollectTask / CollectItem 模型与管理页
- 清洗为 markdown（去脚本/样式）、图片转存本地（默认开启，Q10 轮定）
- 去重、运行历史、立即执行、错误告警（走邮箱提醒 system_error/collect_failed 事件）

### Out of Scope

- 微信公众号文章采集（wechat_mp 源类型预留字段，本期不实现解析器）
- 需登录/反爬目标站（仅支持公开页面）
- 视频等富媒体转存（仅处理图片）

## 6. 约束与依赖

- ADR-003：源清单后台可配置、不预置，运营录入（DEP-004）
- 性能预算（REQ-NF-001）：每源限速 ≥2s、夜间窗口、失败限次

## 7. 验收条件

- [ ] 采集源 CRUD + 解析规则配置 + 立即执行 + 运行历史可查
- [ ] 调度默认每日 1 次（凌晨执行），cron 可改（Q10 轮定）
- [ ] 相同 URL 不重复入库（urlHash 主键级去重）
- [ ] 正文图片默认转存本地（站内链替换；失败降级留原链并标记）（Q10 轮定）
- [ ] 采集条目进入审核队列，支持通过/拒绝/编辑后入库
- [ ] 采集失败产生告警记录（通知网关事件 collect_failed）
- [ ] 首个真实源（运营录入后）端到端跑通：抓取→清洗→去重→待审核

- 管理页 2 个（采集源、采集条目），走 CrudPage 通用组件
