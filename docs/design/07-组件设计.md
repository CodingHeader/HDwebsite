## 3. UI 基础件（components/ui/，shadcn 风格）

button、input、textarea、label、checkbox、switch、select、dialog、tabs、table、scroll-area —— 基于 Radix 原语 + `cn()`（clsx + tailwind-merge）。

## 4. 组件设计约定

- 命名导出 + PascalCase；props 显式 interface；无 `any`。
- 服务端组件优先（数据直查），仅交互叶子用 `"use client"`。
- 样式只走 Tailwind utility；动态样式（渐变/阴影/图标）存 DB 字段由组件读取。
- 图标一律传 Lucide 名称字符串，组件内映射渲染（HomeCard.icon / ManagerMenu.icon / ServiceGuide icon）。

## 6. 补充（2026-10-10 第二轮实测）

### 6.1 图片双组件分工
- `ImageField`：字段级展示 + 选择（回填 url、预览、点击更换）——编辑已有图片引用。
- `ImageUploader`：上传交互（选文件 → FormData → POST /api/upload → 回填 url）。
- 两者最终都收敛到 lib/upload-service（三重校验 + 缩略图 + Media 入库），组件不直接碰上传逻辑。

### 6.2 authStore 细节（zustand + persist）
- persist 中间件落 localStorage（token/user/isAuthenticated）。
- `hasHydrated` 标志解决 hydration 竞态：登录跳转等 useEffect 逻辑须等 hydration 完成再触发；login() 同时置 hasHydrated=true，logout() 清态。
