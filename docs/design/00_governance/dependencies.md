## 4. 变更监控

- DEP-001/003/004 三项为"设计就绪、运营数据后补"型：在 current-plan 与 backlog 中保持可见，任一就绪即更新本表状态并在 changelog 记录。
- 就绪动作：更新本表状态 → changelog 记录 → 关联 backlog 项解除阻塞标注 →（如影响排期）更新 current-plan。
- 到期未就绪：里程碑评审时升级提示（M3 前 SMTP、M4 前微信凭证），不阻塞前置里程碑。
- 内部依赖（DEP-009~014）随 SOL 实施顺序自然满足，里程碑验收时核对。
