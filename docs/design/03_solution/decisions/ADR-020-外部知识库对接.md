# ADR-020 外部知识库对接（项目内不部署）

- **状态**：accepted（2026-10-10 用户确认，**关键转向**）
- **背景**：原方案（12-知识库设计 §3）为项目内三级模型 KnowledgeBase→KnowledgeFile→KnowledgeChunk。
- **决策**：
  1. 知识库能力采用**外部平台**，项目内不部署知识库（选型未定，Dify/FastGPT/内部服务候选）；
  2. 设计抽象 **KBAdapter 适配层**：`search(query, topK)` / `pushFile(file)` / `upsertFile` / `remove`，兼容常见外部库检索/入库 API 形态，具体产品后补配置；
  3. 采集产物（CollectItem 审核通过）经 Adapter 推送外部库（=N6 实现方式变更）；
  4. 现有本地 Knowledge 表 + contains 检索作为**兜底双轨**保留，外部库稳定后评估下线（Q12b）；
  5. 后台"知识库管理"页变为：外部库连接配置 + 检索测试 + 本地兜底条目管理（瘦身后仍需 N7 的管理界面，但管理主体在外部平台）。
- **影响**：SOL-002 范围从"三级模型+管理平台"缩减为"适配层+对接+双轨"；S2 工期下降；12-知识库设计原三级方案转为备选留档；REQ-F-006/007 实现方式更新。
- **关联**：ADR-014/016；SOL-002；REQ-F-006/007。
