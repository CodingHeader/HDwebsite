# ADR-012 闲置资产裁剪

- **状态**：accepted（2026-10-10 用户确认）
- **背景**：PageTemplate/ContentBlock 运行时（templateFile 指向不存在文件）、TemplateBlock、ElementConfig（712 交互点，src 零引用）均"建而未用"。
- **决策**：新仓 schema **不含** PageTemplate/ContentBlock/TemplateBlock/ElementConfig 四模型；设计在 docs/get（01 §9、04 §2、05 §4）留档备查，未来可复活。
- **影响**：数据模型由 31 缩减至 27（再叠合 ADR-001 News 并入 Article → 26），后续新增域模型 ~10 张；前台渲染全部走组件直查，不再有模板层间接。
- **关联**：ADR-001；04-数据设计 §5。
