- **状态**：accepted（2026-10-10 用户确认，**非推荐项**）
- **背景**：重构形态三选一（原地演进/平行新仓/逐模块替换）。
- **决策**：**新建仓库按新架构重写**。现仓（04292309）降级为设计事实源与参照实现；docs/get 全套文档作为新仓唯一输入；新仓完成并验证后切换部署，旧仓归档。
