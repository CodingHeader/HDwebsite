# ADR-005：兼容端点 + 人工余额

## 状态

accepted（2026-10-10 会话决策 C5，用户确认）

## 背景

各供应商（DeepSeek/Modelscope/硅基流动等）均为 OpenAI 兼容协议，但余额查询接口各家不一且部分不开放；单供应商绑定有断服风险（RISK-003）。

## 决策

- LLMProvider 支持配置**任意 OpenAI 兼容端点**（endpoint + apiKey + model 名），不做供应商专有接口适配
- **余额人工填报**：后台填写当前余额 + 阈值，低于阈值触发 llm_balance_low 邮件提醒（人工记账闭环）
- 多 Provider 路由降级体系见 REQ-F-010（priority/isDefault/isFallback）

## 依据

- 用户问答确认（C5 ✅）

## 备选方案

| 方案 | 评估 | 结论 |
| --- | --- | --- |
| 各供应商专有 SDK 适配 | 维护成本高，新供应商接入慢 | 弃 |
| 余额查询 API 自动化 | 各家接口不一且部分不开放 | 弃 |
| OpenAI 兼容协议 + 人工填报余额 | 一套协议通吃，闭环靠阈值提醒 | **选定** |

## 影响

- 余额是快照非实时（人工更新）；提醒基于填报值与阈值的比较
- 供应商专有能力（私有参数）不在范围；以 OpenAI Chat Completions 协议子集为准
