# ADR-027：并行编排与契约冻结

## Context（背景）

- AGENTS.md §4 原先规定：P01~P15 十五个方向**全部串行**，每方向独立验证后才进入下一方向；§5 规定"推送只在 Final 阶段"。
- 用户 2026-10-13 指令要求把 P07~P15 改造成 **3~5 个并行子任务**（K7/K17），与 §4 直接冲突。
- P0~P06 已完成（`upgrade@bb2c0e51364aca4608d2a5832e31462b9c54ccf8`，P06 独立校验 visual 46/46、E2E 8/8、vitest 210 例）。剩余 P07~P15 与 P02~P06 承接项拆为 60 张原子任务卡。
- 并行必须满足两条硬约束：① 两条线写入的仓库路径**零重叠**；② 两条线共享的**契约、迁移、依赖**必须一次性冻结，否则会互相返工。
- 用户裁决 D11 = 2 名执行者（X = A→E + 主持 Wave 2；Y = Wave 0 + B→C→D）；D8 = Wave 0 通过后推送 `upgrade` 与 tag，各线只推自己的 lane 分支。

## Decision（决策）

1. **波次编排**：剩余工作重排为
   - **Wave 0（串行冻结，约 5 人天）**：W0-01~W0-08 在 `upgrade` 上由契约员串行完成，产出冻结 tag `w1-base`。W0-02/W0-03 必须"零行为变化"（只搬迁/新增，不替换调用方）。
   - **Wave 1（两条执行线并行）**：`lane/ui`（A→E）与 `lane/backend`（B→C→D）。所有权矩阵机械校验（重叠 0、越权 0）；唯一中途合并点 M1 = tag `w1-ui-kit`（A-07）。
   - **Wave 2（集成、守卫与终审）**：合并 D→B→C→A→E，建守卫（W2-02/W2-08/W2-09），性能复测，终审推送。
2. **契约冻结面**：`w1-base` 之后以下路径在所有线上**只读**——`src/contracts/**`、`prisma/schema.prisma` 与 `prisma/migrations/**`、依赖（`package.json`/锁文件）、`vitest.config.ts` 与 Playwright 配置。
3. **契约变更请求（CCR）**：Wave 1 内任何线需要改动冻结面或他线文件时，**必须停止该子项**并提交《契约变更请求》（格式见 `parallel-w1/11-验收与审查规程.md` §4）；集成者批准后由契约员在 `upgrade` 上做最小提交并打 `w1-base-ccr-<n>`，各线 `git merge --no-ff` 该 tag。影响 ≥2 条线的请求须 opus 审。
4. **推送与分发（D8）**：Wave 0 独立校验 PASS → 推送 `upgrade` 与 tag `w1-base`；Wave 1 各线只推 `lane/*`；`upgrade` 只由集成者在 Wave 2 推送。
5. **防自证循环**：验收标准由规划阶段写定；执行者执行；判定由**另一条线**的独立验证者只看 `git diff <起点>..<终点>` 与命令结果给出 PASS/FAIL/UNKNOWN。同一卡连续 2 次 FAIL → 熔断，写《失败分析》交用户裁决。

## Alternatives（备选方案与代价）

| 备选 | 说明 | 代价 / 为什么未采纳 |
| --- | --- | --- |
| **继续串行**（维持 AGENTS.md §4 原状） | 风险最低，无需冻结面与 CCR 流程 | 与用户 2026-10-13 指令（3~5 并行）冲突；Critical Path 变长，无法压缩 |
| 三条线并行（UI / 平台 / 运维，K17 默认） | 工期约 35.0 人天 | 用户裁决 D11 = 2 名，故本章以双线（X/Y）为既定方案；所有权矩阵两模式均不相交，可平滑扩缩 |
| 不冻结契约，各线自由改 `src/contracts/**` | 少一道流程 | 两条线共享同一契约源，必然产生语义冲突与返工；违反"唯一共享物"约束 |
| 让守卫（契约测试 / ESLint 边界）与实现并行 | 早暴露问题 | 违反规划总指令 §8.1"Guard 不与实现并行"（K18）；守卫全部移到 Wave 2 |

## Consequences（后果）

- **正面**：两条线可在 Wave 0 之后无通信并行；契约/迁移/依赖只改一次；所有权矩阵使"越界改他线文件"可被脚本机械判定。
- **负面 / 需接受的代价**：Wave 0 约 5 人天的纯冻结投入；两条线在 Wave 2 有一次性合并成本（约 4.25 人天集成）；执行者需理解 CCR 流程，越权一次即 FAIL。
- **对后续方向的约束**：P07~P15 原串行提示词不再单独下发，其内容并入 `parallel-w1/`（见各 `review-prompts/P0X-*.md` 文首取代说明）。
