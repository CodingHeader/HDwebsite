# ADR-039 · 前台冻结例外：移动端导航与悬浮层（V2.0 / ADR-01）

> 状态：Accepted · 日期：2026-10-29 · 对应提交：`88e72d69` · 授权：用户 2026-10-29 裁决

## 背景
用户 2026-10-29 实测反馈并裁决：移动端（手机）打开官网时，顶部导航被压成竖排/两行，悬浮层（FloatingContact）遮挡「立即咨询」与下方卡片；且菜单应以 main 的 9 项为准、院校 13 家。修复必须改 `src/components/web/**` 的 `className` 值，而 REQ-F-014 要求「组件 JSX/className 与 main 逐字一致」，故构成前台冻结例外，需本 ADR 追认，否则后续独立验证无据可依。

## 决策
例外成立。受影响文件（白名单）：
- `src/components/web/FloatingContact.tsx`
- `src/components/web/Navbar.tsx`
- `src/components/web/data/home.ts`

允许在**移动端响应式类**（`md:`/`hidden md:inline` 等）范围内修改 className；桌面端（≥768px）渲染须与 main 一致（`88e72d69` 已实测 ≥768px 零变化）。

## 影响
- **桌面渲染**：`88e72d69` 仅改 `md:` 前缀分支与移动端默认值；桌面（≥768px）实测与改动前逐项一致（Navbar ≥768px 零变化；FloatingContact 桌面 x=1292 / w=132 / h=192，与改动前一致）。
- **非 `md:` 的实质差异（需说明）**：`FloatingContact.tsx` 二维码图标容器 `className="relative"` → `"relative shrink-0"`。`shrink-0` 为非响应式 flex 工具类，仅在 flex 布局下防图标收缩；因图标容器有固定尺寸（`w-48`），桌面渲染无视觉变化，属移动端修复的防御性补充。
- **视觉基线**：基线 `ad4cf70e`（2026-10-27）早于前台改动 `88e72d69`（2026-10-29）→ 视觉基线已 stale，须更新（见 `## 后续`）。
- **`prisma/seed.ts` 说明**：导航种子由 upgrade 自造改为 main 原 9 项菜单（网站首页/关于我们/学历提升/热门院校/热门专业/资讯中心/学习中心/党建专栏/联系我们）、院校 take 8→13。`prisma/seed.ts` 不属于 AGENTS.md §4 冻结面（冻结的是 `prisma/schema.prisma` 与迁移目录），本 ADR 仅记录其理由（`data/navigation.ts` 用中文名精确匹配补二级菜单，改名后 5 组下拉只剩「关于我们」），不构成冻结例外。

## 边界
- **文件白名单**：仅 `FloatingContact.tsx`、`Navbar.tsx`、`data/home.ts`。
- **改动性质**：仅移动端响应式类（`md:`/`hidden md:inline` 等）；桌面端渲染须与 main 一致。
- **理由**：用户 2026-10-29 裁决的移动端遮挡/竖排。

## 不可外推
本条不构成其他前台文件的例外依据。任何其他前台文件的 `className` 改动（含后续新增），须重新裁决并另立 ADR。

## 后续
