# ADR-028：响应与错误体口径

## Context（背景）

- 契约②（`parallel-w1/02-契约冻结包.md` ② Errors）要求错误码覆盖 Wave 1 各线的全部已知失败路径；P13 目标 1 与 REQ-NF-001 要求"错误可预期、前端文案统一"。
- 现网枚举只有 6 值（`src/contracts/common.ts:14-21` 与 `:60-67` 均为 200/400/401/403/404/500），**无法表达**：
  - 409 唯一约束冲突（Prisma P2002 现被 `api-handler.ts:167` 映射为 400，与"字段校验失败"混同，前端无法区分该"刷新后重试"还是"逐字段标红"）；
  - 429 AI 咨询限频、502 上游失败（LLM / 微信 / 采集源）、503 全部模型额度或限频用尽 —— 这三类在 ChatWidget、LLM 网关、采集引擎中均已存在实际失败路径。
- 两个待裁决点（规划 §10 D6/D7，卡片假设 A-W0-1/A-W0-2）：
  - **K9**：400 的错误体是 `data.fieldErrors`（P06 已交付并被 `content-review.test.ts:91` 断言）还是改名为 `data.details`？
  - **K10**：`created()` 的 code 是 200 还是 201？
- 硬约束证据：`src/lib/manager-fetch.ts:73` `if (body.code !== 200) throw new ApiError(...)` —— 管理端**全部**创建操作都以 `code === 200` 判定成功。
- 前端展示口径已由契约②表定稿：409→`toastCopy.conflict`、429→"太频繁"、502→`toastCopy.badGateway`、503→`toastCopy.serviceUnavailable`，且这四类的**错误体为 `null`**（无稳定后端文案）。

## Decision（决策）

1. **错误码枚举扩至 10 值**：`apiResponseCodeSchema` 与 `errorCodes` 同时加入 409 `CONFLICT`、429 `TOO_MANY_REQUESTS`、502 `BAD_GATEWAY`、503 `SERVICE_UNAVAILABLE`（两处必须同步，否则 zod 校验会拒绝新码，违反契约自检）。
2. **`api-response.ts` 新增 4 个工厂**：`conflict()` / `tooManyRequests()` / `badGateway()` / `serviceUnavailable()`，HTTP 与 code 一致，`data: null`；**默认文案直接取 `toastCopy`**（前端展示契约的单一来源）。
3. **`ApiHttpError` 支持 400/401/403/404/409/429/502/503**（导出 `ApiErrorStatus`）；`withApi` 的 `toErrorResponse` 逐一映射到对应工厂。
4. **Prisma P2002 → 409**（唯一约束冲突）；**P2003 维持 400**（外键/关联错误属请求数据问题，本卡不调整）。
5. **保留 `data.fieldErrors`（K9 决议：不改名 `details`）**：P06 已交付、`content-review.test.ts` 已断言、前端 `articles/llm-providers/publish-jobs/wechat-accounts/CrudPage` 五处已按 `fieldErrors` 接收。改名收益为零、跨线代价大。
6. **`created()` 维持 code 200 + HTTP 201（K10 决议）**：改 code 会让 `manager-fetch.ts:73` 判定失败，管理端全部创建操作报错；除非同期改 `manager-fetch` 与所有调用方（跨线、且丢失"创建"与"成功"的区分价值）。
7. **`managerFetch` 契约**：`ApiError` 新增 `fieldErrors?: Record<string, string>`（从 `data.fieldErrors` 白名单式提取，仅保留 string 值）；错误文案 `CODE_COPY[code] ?? (body.message || toastCopy.failed)`。
8. **`SchemaForm` 可见性**：`FieldSpec.visibleTo?: "super"`；`visibleFields()` 过滤 + `validateRequired(..., isSuper = true)` 跳过隐藏字段（默认值保持既有调用方行为）。`isSuper` 取自 `useAuthStore.user.role.isSuper`（已存在于持久化会话，无需新增 `/api/auth/me` 调用）。
9. **非 JSON 例外**（登记口径，**常量与守卫文件由 W2-02 待建**；本卡提交时 `tests/contract/` 尚不存在，W0-07 才把 `tests/contract` 收编进 vitest）：`/api/file/[...path]`（文件流）、`/api/wechat/callback`（XML/echostr）、`/api/chat/stream` 的成功流体（SSE；失败仍为 JSON 信封）。

## Alternatives（备选方案与代价）

| 备选 | 说明 | 代价 / 为什么未采纳 |
| --- | --- | --- |
| `data.fieldErrors` 改名 `data.details`（K9 备选） | 语义更泛化 | 需同步 P06 已交付实现 + `content-review.test.ts` + 5 处前端接收点，跨线返工；且 J 系列不一致清单无此诉求 |
| `created()` 改 code 201（K10 备选） | HTTP 语义更标准 | `manager-fetch.ts:73` 会让管理端**所有**创建操作抛错；修复需同卡改跨线文件（越界），或不改则全局回归 |
| P2002 维持 400 | 零改动 | 与语义不符：前端无法区分"唯一冲突（应刷新后重试）"与"字段错误（应逐项标红）"；契约②表已定稿为 409 |
| 409/429/502/503 使用后端 `message` | 保留具体原因 | 契约②表规定这四类**错误体为 null**，后端文案不稳定；前端统一取 `toastCopy` 才能保证中文与一致性 |
| 只加 `errorCodes` 常量、不扩 zod union | 改动更小 | `apiResponseCodeSchema` 是响应校验唯一源，不同步会让新码在契约测试中被拒 → 契约自检不通过 |
| 为 `visibleTo` 新建独立组件 | 隔离更彻底 | 违反"不为将来可能需要提前抽象"；`SchemaForm` 是既有表单唯一入口，就地扩展即可 |

## Consequences（后果）

- **正面**：错误码语义完整且可被契约测试机械校验；错误文案单一来源（`toastCopy`）；P2002 语义正确，前端可给出"刷新后重试"；`fieldErrors` 链路端到端可用（后端 `validationError` → `managerFetch` → 表单逐项标红）。
- **负面 / 需接受的代价**：
  - 至少 1 处既有断言需同步：`src/lib/__tests__/api-contract/with-api.test.ts` 的「P2002 → 400」已改为 409（本卡允许面内）。
  - **遗留待收敛（登记待办）**：`src/app/api/articles/route.ts:161` 与 `src/app/api/articles/[id]/route.ts:217` **自行捕获** P2002/P2003 并返回 400，未走 `withApi` 的映射。它们不在本卡允许面内，需由 B-02/B-03（withApi 迁移）收敛为 409；在此之前"P2002 → 409"仅在 `withApi` 路径上成立。
- **对后续方向的约束**：Wave 1 冻结期内（`w1-base` 之后）改动 `errorCodes` / `toastCopy` / `ApiHttpError` 状态集，必须走《契约变更请求》（ADR-027 §3）。

## 附录：错误码 ↔ HTTP ↔ 错误体 ↔ 前端展示（冻结面）

| code | HTTP | 场景 | 错误体 | 前端展示 | 生产方 |
| --- | --- | --- | --- | --- | --- |
| 200 | 200 / 201(created) | 成功 | `data` 为结果 | 成功 toast（`toastCopy`） | 全部 |
| 400 | 400 | zod 校验失败、业务规则拒绝（含知识库 PDF/图片、内容状态非法迁移） | `data: { fieldErrors }` 或 `null` | 字段 aria-invalid + 首条 message toast | `validationError()` / `ApiHttpError(400)` |
| 401 | 401 | 未登录/令牌过期 | `null` | 跳转 `/manager/login` | `unauthorized()` |
| 403 | 403 | 无权限（含非超管开启 autoApprove） | `null` | Forbidden 视图 / toast | `forbidden()` / `ApiHttpError(403)` |
| 404 | 404 | 资源不存在 | `null` | Empty/Error 视图 | `notFound()` / `ApiHttpError(404)` / P2025 |
| 409 | 409 | 唯一约束冲突（Prisma P2002） | `null` | `toastCopy.conflict` | `conflict()` / P2002 映射 |
| 429 | 429 | AI 咨询限频（每 IP 每分钟 10 次） | `null` | `toastCopy.tooManyRequests` | `tooManyRequests()` / `ApiHttpError(429)` |
| 500 | 500 | 未捕获异常（不泄漏堆栈；触发 system_error 邮件） | `null` | `toastCopy.failed` | `serverError()` |
| 502 | 502 | 上游失败（LLM / 微信 / 采集源） | `null` | `toastCopy.badGateway` | `badGateway()` / `ApiHttpError(502)` |
| 503 | 503 | 全部模型额度/限频用尽 | `null` | `toastCopy.serviceUnavailable` | `serviceUnavailable()` / `ApiHttpError(503)` |
