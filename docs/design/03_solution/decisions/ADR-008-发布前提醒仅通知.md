# ADR-008：发布前提醒仅通知

## 状态

accepted（2026-10-10 会话决策 C8，由 N11 语义澄清产生，用户确认）

## 背景

原始需求"发布新闻前提醒"存在歧义：是"通知相关人"还是"等待人工批准后才发"？若为审批门则定时发布链路被阻塞（waiting_confirm 状态、催办、超时策略等复杂度陡增），与"自动发布"目标冲突。

## 决策

**仅通知**，非审批门：

- 定时发布：按提前量（默认 30 分钟，可配）发出提醒邮件，到点照常自动发布
- 立即发布：发出"即将发布"即时通知
- 提醒只是知会，不阻断、不等待确认

## 依据

- 用户问答确认（N11 语义 → C8 ✅）

## 备选方案

| 方案 | 评估 | 结论 |
| --- | --- | --- |
| 审批门（waiting_confirm 状态） | 阻塞自动发布，需催办/超时策略 | 弃 |
| 通知/审批双模式可配 | 状态机复杂度翻倍，无明确需求方 | 弃 |
| 仅通知 | 链路简洁，契合"自动发布"目标 | **选定** |

## 影响

- PublishJob 状态机不含 waiting_confirm，链路简洁
- 若未来需要审批制，走新 ADR 扩展（状态机预留 cancelled 语义可承接撤回）
