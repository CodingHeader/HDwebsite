# ADR-007：英文草稿删除

## 状态

accepted（2026-10-10 会话决策 C7，已执行）

## 背景

docs/get/ 曾同时存在两套体系：本会话的中文提取体系（README + 01~16 + talk.md）与另一并发会话遗留的 14 个英文草稿（00_requirements.md ~ 13_resources.md）。英文草稿为通用化模板内容，非基于本项目代码提取，与中文体系冲突（C7 冲突登记）。

## 决策

删除全部 14 个英文草稿文件，docs/get/ 以中文提取体系为唯一权威。

## 执行记录

- 2026-10-10：正则 `^\d{2}_` 匹配删除 14 个文件，复核余 18 个根文件（README + 01~16 + talk.md）
- README.md §3/§4 已登记 C7 解决状态

## 备选方案

| 方案 | 评估 | 结论 |
| --- | --- | --- |
| 两体系合并 | 英文草稿为泛化模板无实证价值，合并即污染 | 弃 |
| 移入 09_archive 保留 | C7 已判定无价值，徒增索引噪音 | 弃 |
| 删除并留 ADR 记录 | 体系唯一化，决策可追溯 | **选定** |

## 影响

- 文档体系唯一化，消除双源歧义
- 过程教训沉淀：LL-001（并发会话双体系风险，今后单会话产出原则）

- lessons-learned LL-001；RISK-004（已缓解）
