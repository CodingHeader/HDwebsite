# ADR-003：采集源后台配置、不预置

## 状态

accepted（2026-10-10 会话决策 C3，用户确认）

## 背景

"采集各大学校、部门政策新闻"的源清单依赖运营方业务认知（目标院校/省份/栏目），预置清单既不权威也易失效（DEP-004 黄灯）。

## 决策

- 源清单完全后台可配置（CollectSource CRUD + 解析规则 + 目标知识库 + 自动标签），不预置任何源
- 默认调度：每日 1 次（cron 可改）；提供"立即执行"用于调试与补采
- 每个源首次配置后由运营用"立即执行"验证抓取效果

## 依据

- 用户问答确认（C3 ✅）
- REQ-C-003（人工运维、一切后台化）

## 备选方案

| 方案 | 评估 | 结论 |
| --- | --- | --- |
| 预置常见源清单 | 不权威、易失效、维护负担在开发侧 | 弃 |
| 配置文件硬编码 | 违背后台化原则（REQ-C-003），改源需发版 | 弃 |
| 后台 CRUD + 试抓预览 | 运营自助、即配即验 | **选定** |

## 影响

- 采集验收以"首个运营录入源端到端跑通"为准（REQ-F-002），不承诺内置源数量
- 解析规则需可视化配置 + 试抓预览降低运营门槛（SOL-004 详设）
