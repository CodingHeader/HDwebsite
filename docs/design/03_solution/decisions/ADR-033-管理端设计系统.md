# ADR-033 · 管理端设计系统：新建 manager/ui 而非改 ui/（A-01，2026-10-16）

> 状态：已采纳。来源：REQ-F-015（管理端顶级体验）、P07 组件检查点、V0.6 DR-13/P-7。
> 执行线：A 管理端组件库（lane/a-manager-ui）。

## 1. 决策

管理端标准基础件落在 `src/components/manager/ui/`（新目录），**不修改** `src/components/ui/` 的 6 个前台在用文件（button/input/textarea/label——与 origin/main 逐字一致，REQ-F-014 前台冻结；管理端登录页在用）。

### 1.1 理由

1. **前台冻结（REQ-F-014）**：`src/components/ui/button.tsx` 等与 main 逐字一致，是 visual 46/46 门禁的基准面；任何 className 改动都会破坏像素一致。
2. **令牌隔离（AGENTS.md §3）**：管理端令牌（mgr-*）只能写在 `[data-theme="manager"]` 作用域内；manager/ui 全部依赖 mgr-* 令牌，与前台组件的令牌体系天然分离。
3. **演进自由**：管理端要"顶级、极度友好"（REQ-F-015），需要独立的设计系统演进（A-02 DataTable、A-03 ResourceForm、A-07 发布点），不受前台组件 API 冻结约束。

### 1.2 UI 库选型（P-7）

- REQ-C-001 原文写 Radix；827646b 检查点已改用 **@base-ui-components/react 1.9.0**（依赖已在锁定文件内，Wave 0 冻结不加依赖）。本 ADR 记录取代：**base-ui 取代 REQ-C-001 中的 Radix**。
- 现有 manager/ui 控件（Input/Select/Checkbox/Switch）为原生控件美化（P07 口径：键盘与读屏原生可用）；浮层件（Tooltip/Popover/DropdownMenu/Sheet/Combobox）用 base-ui 原语（dialog-primitive.tsx 已是此口径）。

## 3. 影响

- `feedback/styles.ts` 的 `btnCls`/`inputCls` 已与组件共用同一套类名（buttonClass/controlClass）；剩余 37 处引用替换跨 A-06~A-08 完成（DR-13）。
