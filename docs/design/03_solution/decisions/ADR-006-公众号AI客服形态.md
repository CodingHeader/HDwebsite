# ADR-006：公众号 AI 客服形态

## 状态

accepted（2026-10-10 会话决策 C6，用户确认）

## 背景

微信被动回复限 5s，AI 生成（含知识检索 + 模型推理）常超 5s（REQ-C-002）；直接超时则用户收不到任何应答。

## 决策

采用"快速应答 + 异步补发"：

1. 收到文本消息 → 5s 内被动回复固定应答（"正在为您查询…"，或配置话术）
2. 异步执行：知识检索 + llm-gateway 生成（ChatScene 默认 faq）
3. 48h 窗口内经客服消息接口下发完整答案；超长截断 + 引导官网查看

WechatAccount.aiEnabled 开关 + 场景绑定（话术 ChatScene 配置）。

## 依据

- 用户问答确认（C6 ✅）
- 微信平台约束（5s/48h 硬限制）

## 备选方案

| 方案 | 评估 | 结论 |
| --- | --- | --- |
| 纯被动回复（压缩答案进 5s） | 答案质量差，知识检索+推理难达标 | 弃 |
| 被动回复超时重试 | 微信侧仍可能超时，体验抖动 | 弃 |
| 两段式：快速应答 + 48h 客服消息补发 | 契合平台限制，答案完整 | **选定** |

## 影响

- 用户体验为两段式应答（先提示后答案）；需客服接口权限（认证服务号）
- AIChatHistory 记录渠道维度（website/wechat）以便审计
