# ADR-021 部署切换灰度发布

- **状态**：accepted（2026-10-11 用户确认，Q10 轮）
- **背景**：M4 部署切换方式三选一（A 直接切换 / B 双跑对账 / C 灰度发布；ADR-011 仅定"新仓完成并验证后切换"，未定切换方式）。
- **决策**：**灰度发布**（选项 C）。
  1. 新仓独立端口并行部署（推断默认：6790；宝塔 80 反代统一入口不变，旧仓 6789 保持运行）；
  2. 反代按比例分流**前台流量**：10% 起步 → 50% → 100%（推断默认），每步观察 ≥3 天（推断默认），观察项：5xx/报错日志、核心页响应、报名提交成功率；
  3. 写归属：灰度期间写操作（后台/表单提交）仍路由旧仓，dev.db/uploads 每日增量同步至新仓（推断默认，规避 SQLite 双写分叉）；全量切换时短暂冻结写入、完成最终增量同步后，写入统一切新仓；
  4. 异常回滚：反代切回旧仓，分钟级生效；
  5. 全量后旧仓热备 ≥2 周（推断默认，只读保留），期满按 ADR-011 原口径归档。
- **影响**：M4 增补任务（反代分流配置、增量同步脚本、监控观察、回滚演练 → validation-plan M4-7）；REQ-NF-004 部署验收挂 M4-7；ADR-011"完成并验证后切换"细化为本 ADR 灰度口径。
- **关联**：ADR-011/019；milestones §M4；validation-plan §M4（M4-7）；REQ-NF-004。
