# SOL-004：采集引擎

## 1. 目标

可配置源定时抓取院校/部门政策新闻，清洗去重后进审核队列，默认自动入库（pending），供发布与知识库复用。

## 2. 覆盖需求

| 需求 | 覆盖点 |
| --- | --- |
| REQ-F-002 | 源配置/调度/抓取解析/去重/审核队列/告警 |
| REQ-F-006 | 去重通过 → KnowledgeFile(pending) 自动链路 |
| REQ-NF-001 | 限速/窗口/批次超时预算 |

## 3. 设计要点

### 3.1 数据模型

- **CollectSource**：name/type(rss/html)/url/解析规则(listSelector/titleSelector/contentSelector/timeSelector)/cron(默认每日 1 次、凌晨 04:00 执行——避开 03:00 备份错峰，管理端可改，Q10 轮定)/targetBaseId/autoTags/enabled
- **CollectTask**（运行记录）：sourceId/startedAt/finishedAt/status/newCount/errMsg
- **CollectItem**：sourceId/url/urlHash(唯一)/title/summary/publishedAt/status(new/approved/rejected/imported)/targetKnowledgeFileId

### 3.2 执行流程（collect.run 任务，挂调度基座）

1. 到点源逐个执行（并发 1）；HTTP 抓取限速每请求 ≥2s
2. 解析：rss 直取 / html 按选择器抽取；正文清洗为 markdown（去 script/style/导航残留）
3. 正文图片**默认转存本地**（Q10 轮定）：复用 upload-service（下载→sharp→/uploads + Media 记录），正文链接替换为站内链；下载失败降级保留原链并标记
4. 去重：urlHash 主键级拦截；标题相似度（0.9）辅助标记疑似重复
5. 新条目 CollectItem(new)；**默认自动创建** KnowledgeFile(pending, source=collect, targetBaseId+autoTags)（REQ-F-006）
6. 运行记录回写 CollectTask；失败 → collect_failed 事件（邮件告警，10 分钟聚合）

### 3.3 管理界面

- 采集源管理：CRUD + 解析规则配置 + **试抓预览**（保存前实测返回条目列表）+ 立即执行
- 采集条目审核队列：列表/详情预览/通过（转发布排期入口，衔 SOL-005）/拒绝/编辑后入库

### 3.4 边界

- wechat_mp 源类型字段预留不实现解析器（ADR-003 范围外）
- 正文图片**默认转存本地**（Q10 轮定，反转本节原口径）：复用 upload-service 下载→sharp→/uploads + Media 记录，正文链接替换为站内链；下载失败降级保留原链并标记；发布时按渠道处理：官网走站内链、公众号走素材上传

### 3.5 API 与页面

| API | 说明 |
| --- | --- |
| GET/POST /api/collect/sources | 源列表 / 新建（含解析规则 JSON） |
| PATCH/DELETE /api/collect/sources/[id] | 编辑 / 启停 |
| POST /api/collect/sources/[id]/test | 试抓预览（返回解析条目样例，不入库） |
| POST /api/collect/sources/[id]/run | 立即执行（写 CollectTask） |
| GET /api/collect/items | 条目列表（?status=，审核队列） |
| PATCH /api/collect/items/[id] | 通过 / 拒绝 / 编辑后入库 |
| GET /api/collect/tasks | 运行历史（?sourceId=） |

页面：`manager/collect-sources`（含试抓预览抽屉）、`manager/collect-items`（审核队列）。

### 3.6 技术选型（新增依赖声明，REQ-C-001）

| 依赖 | 用途 | 理由 |
| --- | --- | --- |
| rss-parser | RSS/Atom 解析 | 覆盖主流源格式 |
| cheerio | HTML 选择器解析 | 服务端 jQuery 语义、轻量无原生依赖 |

标题相似度用字符 bigram Jaccard 自实现（约 20 行，不引库）。

### 3.7 风险与缓解

- 目标站反爬/改版导致解析失败 → 试抓预览 + errMsg 留痕 + collect_failed 告警；合规红线：仅公开页、限速 ≥2s（RISK-005）
- 脏数据入库 → 一律 pending 待审核（REQ-F-006），人工过滤后激活

## 4. 数据模型变更

| 模型 | 变更 | 字段要点 |
| --- | --- | --- |
| CollectSource（新增） | — | name/type(rss/html)/url/解析规则(JSON：listSelector 等)/cron(默认 `0 4 * * *` 凌晨执行；可配置，Q10 轮定)/targetBaseId?/autoTags[]/enabled |
| CollectTask（新增） | — | sourceId→/startedAt/finishedAt/status/newCount/skipCount/errMsg |
| CollectItem（新增） | — | sourceId→/url/urlHash(唯一)/title/summary/content/publishedAt/status(new/approved/rejected/imported)/knowledgeFileId? |

## 5. 关键取舍

- 不引入无头浏览器（Puppeteer 超单机资源约束）；仅静态页/RSS
- 相似度用标题字符级（Jaccard/编辑距离实现微决策），不引全文向量比对

## 6. 验证方式（VAL 摘要）

- 试抓预览对 1 个真实 rss 源 + 1 个 html 源成功
- 重复执行同源：urlHash 零重复入库
- 去重通过条目自动出现在目标库 pending 文件列表
