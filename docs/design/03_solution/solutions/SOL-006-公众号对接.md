# SOL-006：公众号对接

## 1. 目标

按官方 API 规范实现公众号接入层：账号管理、自动发文（草稿→发布）、AI 客服（被动+补发）；凭证后补即插桩生效（ADR-002）。

## 2. 覆盖需求

| 需求 | 覆盖点 |
| --- | --- |
| REQ-F-001 | WechatAccount/内容中枢渠道预览/ContentChannel |
| REQ-F-005 | draft/freepublish/素材/token/频控/重试 |
| REQ-F-009（公众号端） | 回调验签/被动回复/客服消息补发/风控 |

## 3. 设计要点

### 3.1 账号与验签

- **WechatAccount**：name/appid/appSecret(加密)/token/aesKey(明文模式可空)/aiEnabled/sceneId(默认 faq)/status
- token 管理：缓存（7200s，过期前 5min 刷新）；获取失败重试 + 告警
- `/api/wechat/callback`：GET echostr 验签；POST XML 解析 → 事件分发（subscribe/文本消息）

### 3.2 自动发文（挂 SOL-005 发布队列）

- wechat 执行器：正文图片逐张上传永久素材替换为微信域 URL → 封面 thumb_media_id → `draft/add` → 按 WechatAccount.freepublishEnabled 决定 `freepublish/submit`
- 频控：间隔 ≥60s、每日上限 Setting（默认 20）；失败指数退避 ≤3 + 告警
- 回写 ContentChannel：externalId(media_id/publish_id)/externalUrl/status/errMsg

### 3.3 AI 客服（ADR-006 两段式）

1. 文本消息 → 5s 内被动回复话术（"正在为您查询…"，ChatScene.greeting 或专用话术）
2. 异步：SOL-003 网关 + 知识检索生成 → 48h 窗口客服消息接口补发；超 600 字截断 + 引导官网链接
- 风控：用户级限频/黑名单/敏感词（与官网端共用配置）；AIChatHistory(channel=wechat) 留存

### 3.4 内容中枢渠道侧（REQ-F-001）

- 编辑器渠道预览 Tab：公众号样式预览（MarkdownRenderer 简版排版：无外链、图片占位）
- 发布入口四类（官网/公众号/同时/定时）写 PublishJob 两渠道任务

### 3.5 API 与页面

| API | 说明 |
| --- | --- |
| GET/POST /api/wechat/callback | 验签（echostr）/ 消息接入（XML → 事件分发） |
| GET/POST /api/wechat/accounts | 账号 CRUD（appSecret/aesKey 加密落库） |
| PATCH/DELETE /api/wechat/accounts/[id] | 编辑 / 停用 |
| POST /api/wechat/accounts/[id]/test | access_token 获取测试 |

页面：`manager/wechat-accounts`、`manager/content-hub`（内容中枢：列表 + 编辑器 + 渠道预览 Tab，与 SOL-005 共建）。

### 3.6 技术选型（新增依赖声明，REQ-C-001）

| 依赖 | 用途 | 理由 |
| --- | --- | --- |
| fast-xml-parser | 微信 XML 报文解析 | 轻量、无原生依赖 |

验签用 node:crypto 原生实现（sha1 排序校验），不引库。

### 3.7 风险与缓解

- 平台政策变动（接口下线/频控收紧，RISK-002）→ 微信 API 封装收敛单模块 + 版本注释，便于跟进适配
- 凭证泄漏 → appSecret/aesKey 加密落库 + 回显脱敏 + IP 白名单（REQ-C-002）

## 4. 数据模型变更

| 模型 | 变更 | 字段要点 |
| --- | --- | --- |
| WechatAccount（新增） | — | name/appid/appSecret(加密)/token/aesKey?/aiEnabled/freepublishEnabled/sceneId?/status |
| ContentChannel | 与 SOL-005 共建 | channel=wechat 记录（externalId=media_id/publish_id） |

（ContentItem 与 SOL-005 共建，此处不重复定义。）

## 5. 关键取舍

- 凭证后补：全部接口按官方文档封装，联调用例标记"凭证就绪后"
- 群发接口不做（REQ-F-005 范围外）；订阅号降级场景不承诺

## 6. 验证方式（VAL 摘要）

- 验签用例（token 校验通过/篡改拒绝）
- 草稿创建 mock 联调通过；（凭证就绪后）真实发布 1 篇端到端
- 文本消息 5s 应答 + 补发链路日志完整
