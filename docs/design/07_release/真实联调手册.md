# 真实联调手册（微信 / SMTP / Coze）

> V8-INT-01 交付。目标：**凭证到位后 10 分钟内得出结论**，不必翻代码。
> 三个冒烟脚本都在 `scripts/smoke/`，默认 **dry-run（不出网）**，加 `--live` 才真正调用。

## 0. 一句话速查

```bash
node scripts/smoke/wechat.mjs          # 微信：dry-run
node scripts/smoke/wechat.mjs --live   # 微信：真实调用

SMOKE_TO=you@example.com node scripts/smoke/smtp.mjs --live   # SMTP
node scripts/smoke/coze.mjs --live                            # Coze
```

**退出码约定**（三个脚本统一）：

| 码 | 含义 | 说明 |
| --- | --- | --- |
| **0** | 成功 | 全链路通 |
| 1 | 断言失败 | 连通了但结果不符预期（如返回 errcode） |
| 2 | 网络/协议错误 | 超时、DNS、证书等 |
| **3** | **缺凭证** | 会逐条列出缺哪些键，并给补齐路径 |

## 1. 为什么凭证在数据库里，不在 `.env`

这是最容易踩的坑。本项目**不用 env 存第三方凭证**：

| 集成 | 凭证存放位置 | 字段 |
| --- | --- | --- |
| 微信公众号 | `WechatAccount` 表 | `appid` / `appSecret`（`v1:` 前缀 = 加密存储） |
| SMTP | `Setting` 表 | `emailHost` / `emailPort` / `emailSecure` / `emailUsername` / `emailPassword` |
| Coze | `LLMProvider` 表（`kind="coze"`） | `endpoint` / `apiKey`（PAT） / `botId` |

原因：后台可改、加密存储、无需重启。因此冒烟脚本**直接读库**——
如果从 env 读，即使跑通也证明不了"线上能用"。

> 前置：本机需能连到目标库。默认 `DATABASE_URL=file:./prisma/dev.db`；
> 生产环境请显式设置 `DATABASE_URL`。

## 2. 微信公众号

### 2.1 需要什么

| 项 | 从哪来 |
| --- | --- |
| AppID / AppSecret | 微信公众平台 → 开发 → 基本配置 |
| **IP 白名单** | 同一页面 → IP 白名单，必须加入**运行脚本那台机器的公网 IP** |
| 账号类型 | 必须是**已认证的服务号**（订阅号不支持 freepublish） |

### 2.2 怎么配

管理后台 → **公众号账号** → 新增：名称 + AppID + AppSecret，状态启用。
保存时 `appSecret` 会自动加密成 `v1:` 前缀。

### 2.3 脚本做什么（4 步，与真实发布链路一致）

1. `GET /cgi-bin/token` —— 换 access_token
2. `POST /cgi-bin/media/uploadimg` —— 上传正文图（B-07 的正文外链图转存）
3. `POST /cgi-bin/draft/add` —— 建草稿
4. `POST /cgi-bin/freepublish/submit` —— 提交发布

`--live` 会在你的公众号里**真的创建并发布一条"【冒烟测试】请忽略"的图文**，测完请手动删除。

### 2.4 预期输出（成功）

```
[1/4] 获取 access_token
  ✓ access_token=xxxx****xxxx（len=…）  expires_in=7200s
[2/4] 上传正文图（uploadimg）
  ✓ 得到正文图 URL：http://mmbiz.qpic.cn/…
[3/4] 创建草稿（draft/add）
  ✓ media_id=xxxx****xxxx（len=…）
[4/4] 提交发布（freepublish/submit）
  ✓ publish_id=xxxx****xxxx（len=…）
```

### 2.5 失败对照表

| errcode | 含义 | 处置 |
| --- | --- | --- |
| **40164** | IP 不在白名单 | 把本机公网 IP 加进微信后台 IP 白名单（最常见） |
| 40125 | AppSecret 无效 | 到微信后台重置 AppSecret 并重新保存 |
| 40013 | AppID 无效 | 核对 AppID |
| 48001 | 接口未授权 | 账号不是已认证服务号，或未开通该接口权限 |
| 45009 | 接口调用超限 | 等配额恢复 |
| 40007 | media_id 无效 | 草稿创建失败导致，先修第 3 步 |

## 3. SMTP

### 3.1 需要什么

| 项 | 说明 |
| --- | --- |
| 服务器地址 / 端口 | 如 `smtp.qq.com:465`（SSL）或 `:587`（STARTTLS） |
| 账号 / 密码 | **多数邮箱要用「授权码」，不是登录密码** |
| 测试收件人 | 通过环境变量 `SMOKE_TO` 传入（不写进库，避免污染收件人列表） |

### 3.2 怎么配

管理后台 → **站点设置 → 邮件**，填 5 个字段。
然后：

```bash
SMOKE_TO=you@example.com node scripts/smoke/smtp.mjs --live
```

### 3.3 脚本做什么

1. `transporter.verify()` —— 连接 + 认证
2. `sendMail()` —— 发 1 封"【冒烟测试】HDwebsite SMTP 连通性验证"

### 3.4 失败对照表

| 报错关键词 | 含义 | 处置 |
| --- | --- | --- |
| `Invalid login` / `535` | 认证失败 | 用**授权码**而非登录密码；确认账号已开启 SMTP 服务 |
| `ETIMEDOUT` / `ESOCKET` | 端口不通 | 换 465(SSL) / 587(STARTTLS)；确认出口防火墙放行 |
| `self signed certificate` | 证书问题 | `emailSecure` 设 `true` 走 SSL，或改用 587 |
| `Greeting never received` | 服务器拒绝会话 | 通常是被反垃圾策略拦截，换端口或加白名单 |

## 4. Coze 知识库

### 4.1 需要什么

| 项 | 从哪来 |
| --- | --- |
| Endpoint | 一般是 `https://api.coze.cn` |
| PAT | Coze 平台 → 个人访问令牌，需 **dataset 读写 + document 上传** 权限 |
| Bot ID | 目标 Bot 的 ID |

### 4.2 怎么配

管理后台 → **模型供应商** → 新增：类型选 **Coze**，填 Endpoint / PAT / Bot ID。

### 4.3 脚本做什么

1. `POST /v1/datasets` —— 建库（名字 `smoke-<时间戳>`）
2. `POST /v1/datasets/{id}/documents/upload` —— 上传 1 个 `.md`
3. `POST /v1/datasets/{id}/retrieve` —— 用"冒烟测试标记"检索

> **`--live` 会在你的 Coze 空间真的建一个库**，测完请手动删除（脚本会打印库名）。

### 4.4 失败对照表

| 现象 | 含义 | 处置 |
| --- | --- | --- |
| `code=4100` / 权限相关 | PAT 权限不足 | 重新生成 PAT，勾选 dataset 读写 + document 上传 |
| `code=700012006` | endpoint 不对 | 确认是 `https://api.coze.cn`（不是 `.com`） |
| 检索返回 0 条 | **正常现象** | 文档解析是异步的，等 30~60s 重试 |
| `code=4000` | 参数错误 | 核对 `format_type`（1=文本，0=自定义分隔符） |

## 5. 常见问题

**Q：脚本报「无法加载解密模块」？**
凭证是加密存储的（`v1:` 前缀），需要用 ts 加载器运行：

```bash
npx tsx scripts/smoke/wechat.mjs --live
npx tsx scripts/smoke/smtp.mjs --live
npx tsx scripts/smoke/coze.mjs --live
```

**Q：dry-run 断网能跑吗？**
能。所有网络调用都被 `isLive()` 守卫包裹（wechat 4 处、coze 3 处，smtp 用 nodemailer）。
dry-run 只打印请求摘要，密钥一律掩码成 `***`。

**Q：如何确认脚本没有偷偷出网？**
```bash
grep -c 'if (isLive())' scripts/smoke/wechat.mjs   # 4
grep -c 'await fetch(' scripts/smoke/wechat.mjs    # 4  → 每个 fetch 都有守卫
```

**Q：三个都跑通了，是不是就能上线？**
不等于。冒烟只验证"凭证通、接口调得动"。
上线还需要的：真实内容发布后的**回读一致性**、**失败重试**、**通知到达**——
这些由 e2e（mock 上游）与人工验收覆盖。

## 6. 与 V0.7 的口径关系

按 AGENTS.md §2 的用户裁决：微信/SMTP/Coze 凭证不提供，**完整实现 + mock 测试 + 真实联调标 UNKNOWN**。

本手册交付后，该 UNKNOWN 的性质变了：

| | 之前 | 现在 |
| --- | --- | --- |
| 状态 | UNKNOWN（无法验证） | **UNKNOWN（可 10 分钟内验证）** |
| 缺什么 | 凭证 + 验证手段 | **只缺凭证** |

凭证到位后，按本手册跑一遍即可把 UNKNOWN 转成 PASS/FAIL。
