## 1. 前台交互全景

### 1.1 全局交互
| 组件 | 交互 |
| --- | --- |
| TopBar / TopBanner | 通知文案滚动展示、联系电话直拨（tel: 链接） |
| Navbar / Header / Navigation | 多级下拉菜单（linkType=dropdown）、激活态指示器（activeIndicator 配置）、hover 效果（hoverEffect JSON：bg-change 等） |
| SearchBox | 关键词搜索（跳文章列表 keyword） |
| Breadcrumb | 面包屑导航 |
| FloatingContact | 悬浮球四入口（在线客服→/apply?source=float、官方微信→二维码浮层、校长电话→tel 拨号、回到顶部→平滑滚动）；带 FLOAT-001~015 静态标记，无埋点上报（见 §4） |
| Footer | 底部信息、快捷链接 |

### 1.2 首页区块交互
- Banner 轮播：自动播放（默认 5000ms，ContentBlock config 可调）、指示点。
- FourCards 四宫格：icon + 渐变（gradient/hoverGradient/shadow 存 DB）、hover 渐变切换、整卡跳转。
- HotMajor：圆形图标（text 渐变或 image）、hover 跳转报名。
- StatsBanner：数字统计展示（Setting 配置）。
- NewsSection / CourseSection / CampusSection：区块级列表 + "更多"入口。

### 1.3 列表与详情交互
- CategoryFilter：分类/标签筛选（客户端过滤或 URL 参数）。
- 分页：服务端分页（page/limit），前端 Pagination 组件复用。
- ArticleContent：富文本/HTML 渲染（TipTap 产物）。
- 图片懒加载与响应式（Tailwind mobile-first）。

### 1.4 报名转化交互（核心转化路径）
- ApplyForm：姓名/电话/意向/留言 → `/api/students`（status=pending）→ 成功反馈。
- Apply 页侧栏：场景化（ChatScene.sidebarTitle/processSteps/promiseList/contactCardTitle 驱动渲染）。
- AI 咨询窗：欢迎语（greeting）→ 多轮对话 → 知识库加持回答；`knowledgeHit` 命中提示。（注：ChatScene.starters 快捷提问仅后台可配置，前台 apply 页未渲染——死字段，重构期接线或移除）

## 2. AI 聊天交互规格（现状）

| 要素 | 规格 |
| --- | --- |
| 消息上限 | 单条 ≤4000 字，历史 ≤40 条（zod） |
| 场景切换 | sceneCode（apply/float/guide/faq…） |
| 响应形态 | 非流式（stream:false），一次性返回 |
| 容错 | 上游 5xx 自动短重试；超时 88s |
| 元信息 | reply/model/tokensUsed/responseTime/scene/knowledgeHit |

> 重构期（N9/N10）：支持流式输出（SSE）、多模型降级在代理内完成、公众号端适配（被动回复 5s 限制 + 客服接口异步补发）。

## 3. 后台交互规格

| 组件 | 交互 |
| --- | --- |
| 登录页 | 表单登录 → token 存 zustand（authStore）→ 路由守卫 |
| Sidebar | ManagerMenu 表驱动、按权限过滤、badge 提示、多级折叠 |
| SchemaForm | settings-registry / block-registry 驱动的动态表单（type=text/number/boolean/json/color/select/image…，colSpan 布局，zod 校验） |
| RichTextEditor | TipTap 工具栏（加粗/斜体/下划线/对齐/链接/图片/占位） |
| ImageUploader / ImageField | 拖拽/点选上传 → `/api/upload` → 回填 url；缩略图预览 |
| Pagination | page/limit/total/totalPages 标准分页 |
| 列表页通用模式 | 搜索栏 + 筛选 + 表格 + 行操作（编辑/删除/状态切换）+ 新建弹窗（Dialog） |

## 4. 埋点与行为追踪（ElementConfig + UserAction）——⚠️ 管线未接线

埋点数据管道整体未打通，三层均为"半成品"（代码实证）：

| 层 | 设计意图 | 实际状态 |
| --- | --- | --- |
| ElementConfig | 设计期"712 交互点"登记表（elementId 三位-三位编号、layer 1-14 层级，normal/hover/active 三态样式 JSON + interactions），配置驱动交互 | schema 有表（schema.prisma:565），src 零引用——纯蓝图，无任何组件读取 |
| data-interaction-id | 元素级标记，供埋点监听定位 | 静态属性散布 TopBar/Navbar/Header/FloatingContact 约 24 处（FLOAT-001~015、001-001 等），无任何点击/曝光监听 |
| UserAction | 运行期上报 click/view/submit + actionTarget + session/ip/ua/pageUrl/referrer | 模型、/api/user-actions、后台"行为追踪"查看页齐备，但前台零调用——死管道，页面永远无数据 |

- **ViewStats**：内容维度浏览聚合（news/course/partner）。
- **重构建议**：二选一——① 接线（全局 click 委托捕获 `data-interaction-id` → 批量上报 UserAction）；② 移除 ElementConfig + UserAction 全套死代码。避免双体系并存。

## 5. 错误与反馈交互

- 前台：路由级 error.tsx / not-found.tsx / loading.tsx。
- 表单：zod 错误消息直接展示（中文文案内置于 schema）。
- 后台：请求失败统一 message toast/提示；401 自动跳登录。

### 6.2 ServiceGuide 六宫格实测（seed-service-guides-v2.mjs）

### 6.3 知识种子 tag 体系（12 条，seed-knowledge-scenes.mjs）
tags 全集：`school` `about` `contact` `zikao` `chengkao` `kaifang` `exam` `enrollment` `process` `policy` `fee` `major` `discount`（多数条目 2–4 个 tag 组合）
> ChatScene.knowledgeTags 白名单即取值于此；知识库三级模型重构时该批 tag 应映射为库/文件级元数据（→ 12-知识库设计 §4）。
