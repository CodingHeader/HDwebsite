# 06 DAG · 所有权 · 档位（V1.2）

## 1. 依赖 DAG（主干）

```
V12-G-01 ─┬─→ V12-E2E-01（main-agent，先占用 chat 变更区）
          ├─→ V12-E2E-02（P2，仅 tests/e2e/mobile-375.spec.ts，与 E2E-01 并行）
          ├─→ V12-VIS-01（main-agent + CI，与 E2E 完全并行，区域不相交）
          │
V12-E2E-01 ──→┐
V12-E2E-02 ──→ V12-E2E-03（P1 整合：全量 e2e 复跑 + 推送 + CI 绿）──→ V12-REL-01
V12-VIS-01 ───────────────────────────────────────────────────────────┘
V12-Q2-01（blocked, 待用户裁决，独立分支不影响主干）
```

**环检测**：无环（全部有向边从低依赖向高依赖；E2E-03 最下游）。

**关键路径**：G-01 → E2E-01 → E2E-03 → REL-01（决定整体工期；VIS-01 并行不占路径）。

## 2. 并行判定（机械规则）

| 并行对 | 无共享可变状态 | 契约冻结 | 文件所有权不相交 | 不共用迁移 | 判定 |
|---|---|---|---|---|---|
| E2E-01 ∥ E2E-02 | ✓（西：chat 变更区；东：仅 mobile-375.spec） | ✓（0 增量） | ✓ | ✓（0 迁移） | **可并行** |
| E2E-01 ∥ VIS-01 | ✓（分诊不写 src） | ✓ | ✓ | ✓ | **可并行** |
| E2E-02 ∥ VIS-01 | ✓ | ✓ | ✓ | ✓ | **可并行** |
| E2E-03 ∥ 任一 | ✗（同一共享工作树跑全量 e2e） | — | — | — | **串行** |
