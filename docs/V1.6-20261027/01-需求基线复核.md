# 01 · 需求基线复核

> 本轮不新增需求。下列为剩余 4 卡**反向追溯**到的需求条目，用于证明"每张卡都不是凭空造的"。

## 一、复述

V1.5/V1.6 剩余工作的本质：**REQ-F-015「管理端顶级体验」的 8 条可验收量化中，有 3 条至今无运行时证据**。

原文 `REQ-F-015 §5` 要求"顶级设计、极度友好"。`V1.4/06-验收体系 §四` 已把它量化为 8 条（Q1~Q8）。当前状态：

| # | 可查项 | 状态 | 证据 |
|---|---|---|---|
| Q1 | 每页有 PageHeader | ✅ 已证 | `V15-AUDIT-FIX-01`：缺口 0 |
| Q2 | 无原生 `<table>/<input>/<select>/<button>` | ✅ 已证 | 审计 `native: 0` |
| Q3 | 无 `window.confirm` / `alert(` | ✅ 已证 | 审计 `feedback: 0` |
| **Q4** | **五态组件化（空/加载/错误/无权限/成功）** | ❌ **无运行时证据** | 矩阵 42 行该列全"待核" |
| **Q5** | **键盘可达（焦点陷阱/Esc/⌘+S）** | ❌ **无运行时证据** | 同上 |
| **Q6** | **375px 核心操作可完成 + 命中区 ≥44px** | ❌ **无运行时证据** | 同上（仅 3/42 路由有 e2e） |
| Q7 | axe serious/critical = 0 | ✅ 已证 | CI a11y 17 例 |
| Q8 | 只用 `mgr-*` 令牌 | ✅ 已证（含 2 例外） | `V15-TOKEN-01` |

**结论：剩余 4 卡 = Q4 + Q5 + Q6 的补证 + 收口。** 无一卡是"新想法"。
