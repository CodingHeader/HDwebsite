## K1 · Tab 顺序（42 页）

### 每页动作

1. 浏览器地址栏按 Tab 进入页面
2. 连续 Tab，记录焦点序列（可用 `document.activeElement` 在 console 打日志辅助）
3. 判：是否与视觉顺序一致（从上到下、从左到右），有无跳跃/回跳

### 判定

| 结果 | 判据 |
|---|---|
| PASS | 顺序合理，无跳跃 |
| FAIL | 有跳跃/回跳（记具体位置） |
| N-A | `news`（无 UI） |

## K2 · 主操作可聚焦（42 页）

### 每页动作

1. Tab 到"新建"（列表页）或"保存/提交"（表单页）
2. 焦点落在该按钮
3. 按 Enter
4. 判：是否触发（弹窗打开 / 保存成功）

### 判定

| 结果 | 判据 |
|---|---|
| PASS | 可 Tab 到 + Enter 触发 |
| FAIL | 不可达 / Enter 无反应 |
| N-A | 纯只读页（无主操作） |

## 落 matrix

matrix 的 K1/K2 列写具体操作，例如：

```
K1: PASS：Tab 序列 → 侧栏"文章管理"→ 搜索框 → 筛选 → 新建 → 表格首行 → 行操作，顺序合理
K2: PASS：Tab 到"新建"→ Enter → 弹窗打开
```

**反例（判 FAIL）**：`K1: PASS`（无内容）
