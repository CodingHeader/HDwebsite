# 02 · 契约冻结包（六份）

> **本轮 0 契约变更。** 沿用 V1.4/V1.5 冻结状态，`src/contracts/**` 只读。
> 本节不是重新设计，是**验收所需的接口事实清单** —— 执行者据此知道"该期待什么行为"。

## 唯一源

`src/contracts/**`（zod schema，机器可校验）
校验方式：`npm run typecheck` + 契约单测
**禁止**在路由/组件内重复定义 DTO（`AGENTS.md §4`）

---

## ① API 契约

**形态**：REST，前缀 `/api/`，共 126 个 `route.ts`。

**统一信封**（`src/contracts/common.ts`）：
```ts
{ code: number, data?: T, message?: string, fieldErrors?: Record<string,string> }
```

**本轮验收会调用的接口**：

| 用途 | 方法 | 路径 | 备注 |
|---|---|---|---|
| 健康检查 | GET | `/api/health` | 200 |
| 登录 | POST | `/api/auth/login` | 返回 `{data:{token,user}}`；限流 10/60s |
| 各资源 CRUD | GET/POST/PATCH/DELETE | `/api/<resource>` | 由 `crudPageSpecs` 驱动 |
| 文章列表 | GET | `/api/articles?page=1` | 分页信封 |
| 知识文件 | GET | `/api/knowledge-files?trash=0` | 回收站用 `trash=1` |

**分页格式**：`{ code:200, data:{ list:T[], total:number, page:number, pageSize:number } }`

**幂等**：采集 `urlHash` 唯一键；发布 `ContentChannel.externalId`

**鉴权**：管理端需 `Authorization: Bearer <JWT>`，缺失 401、越权 403

## ② Errors 契约

**错误体**：`{ code:number, message:string, fieldErrors?:Record<string,string> }`

**码段**：

| 段 | 语义 | 典型 |
|---|---|---|
| 0 | 成功 | 200 |
| 1xxx | 参数/校验 | 1001 |
| 2xxx | 认证/权限 | 2001 未认证、2002 无权限 |
| 3xxx | 资源 | 3001 不存在、3002 冲突 |
| 5xxx | 服务端 | 5001 |

**前端映射**：`src/lib/manager-fetch.ts` 的 `isForbidden()` / `errorMessage()`；未知码 → 通用文案（不透传原始 message）

**本轮相关**：验收中触发 403 时复用 `Forbidden`（`CrudPage.tsx:333`）。**无新增错误码**。

## ③ Identity 契约

**用户 ID**：`Int` 自增

**角色**：`ADMIN | EDITOR | VIEWER`（`src/contracts/auth.ts`）

**Session**：`JWT_SECRET ≥32位`，cookie 承载

**验收可用的测试账号**（`tests/e2e/global-setup.ts` 实测）：
- `admin` / `admin123`（seed 默认，`prisma/seed.ts:117`）
- `e2e-viewer` / `viewer123`（e2e 幂等创建，`global-setup.ts:167`）
- e2e.db 中两个账号均存在（实测 `readFileSync('prisma/e2e.db')` 含 `e2e-viewer`）

**权限边界（越权路径明确禁止）**：

| 路径 | 访客 | VIEWER | EDITOR | ADMIN |
|---|---|---|---|---|
| 前台 16 页 | ✅ | ✅ | ✅ | ✅ |
| `/api/articles` GET | ✅ | ✅ | ✅ | ✅ |
| `/api/articles` 写 | ❌401 | ❌403 | ✅ | ✅ |
| `/manager/**` | ❌跳登录 | ✅只读 | ✅ | ✅ |
| `/api/settings` | ❌ | ❌403 | ❌403 | ✅ |
| `/api/users` 管理 | ❌ | ❌ | ❌ | ✅ |

**明确禁止**：前台组件 import `src/components/manager/**`（ESLint 边界守卫）；管理端令牌泄漏到 `[data-theme="manager"]` 外

## ④ Resources 契约

**URL 规则**：存 `DATA_DIR/uploads/`，对外 `/uploads/<filename>` 或 `/api/uploads/<filename>`

**图片白名单**（`next.config.ts:19-23`）：`mmbiz.qpic.cn`、`www.hd1994.com`、`localhost`

**上传鉴权**：JWT + EDITOR 以上；MIME 魔数校验（非扩展名）；20MB

**知识库上传限制**（ADR-025）：仅 `.docx/.doc/.md/.markdown/.txt`；拒绝 PDF 与图片

**生命周期**：孤儿扫描 `scripts/scan-orphan-uploads.mjs`

## ⑥ UX States 契约（本轮验收核心）

### 五态定义与组件

| 态 | 组件 | 触发 | 必备元素 |
|---|---|---|---|
| 空 | `EmptyState` | 列表 0 条 | 图标 + 说明 + **下一步动作** |
| 加载 | `PageSkeleton` / `TableSkeleton` | 首次请求中 | 骨架，不闪烁 |
| 错误 | `ErrorState` | 请求失败 | 说明 + **重试按钮** |
| 无权限 | `Forbidden` | 403 | 说明 + 返回入口 |
| 成功 | `Toaster` / `toast` | 操作完成 | 文案具体（非"操作成功"） |

**组件路径**：`src/components/manager/feedback/`（`EmptyState.tsx`、`ErrorState.tsx`、`PageSkeleton.tsx`、`TableSkeleton.tsx`、`TableState.tsx`、`Forbidden.tsx`、`Toaster.tsx`、`toast.ts`）

### 关键实现事实（验收判据的依据）

**`CrudPage.tsx` 提供 A 类 27 页的五态**：
- `:333` `if (isForbidden(error)) return <Forbidden message={error.message} />;`
- `:370` `<PageHeader title={spec.title} description={spec.description} actions={createBtn} />`
- 文件头 `:1-10` 声明："五态：骨架 / 空（带下一步）/ 错误 + 重试 / 无权限 / Toast"

**`DataTable.tsx:8`**："行操作统一渲染为行内文字按钮（≥ md）/ 卡片底部按钮（< md），aria-label 带对象名"
→ 这是 M4（375px 卡片模式）的实现依据

### 375px 契约
- 断点：`md`（Tailwind 默认 768px）
- 375 下应为卡片布局而非表格横向滚动
- 命中区 ≥44px（Q6）
