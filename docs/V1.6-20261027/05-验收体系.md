# 05 · 验收体系与判据

## 一、体检策略（用户指令落地）

```text
单张卡只跑它改到的测试。
每个阶段做完，只给这个阶段动过的模块体检一次。
全量回归等全部完成或发版前统一跑一次。
```

### 1.1 本轮体检表

| 阶段 | 只跑 | 耗时 |
|---|---|---|
| S2-1~S2-2（五态） | 无命令，人工逐页 | — |
| S2-3~S2-4（键盘） | 无命令，人工逐页 | — |
| S2-5（M1 溢出） | `npx playwright test tests/e2e/mobile-375.spec.ts`（**需 Linux**；本机 win32 不可跑，改用脚本直接量 `scrollWidth`） | ~2 分钟 |
| S2-6（375 人工） | 无命令，人工逐页 | — |
| S3（收口） | 全量 8 项门禁（**唯一一次**） | ~8 分钟 |

### 1.2 win32 限制与绕行

`next.config.ts:7`：`output: isWindows ? undefined : "standalone"`

- `npm run test:e2e` / `test:visual` 在 win32 跑不了（需 Linux/Docker）
- **M1 绕行**：不起 playwright，直接用 Node + CDP 或简单 fetch 量 `scrollWidth` 不可行（需渲染）
- **可行方案**：本机 `npx next start` + Playwright **仅 headless chromium**（chromium 已装），不依赖 standalone

**结论**：M1 可在本机跑，只要用 `npx next start` 而非 standalone server。已验证 V1.4 时本地跑过 45 例 visual。

## 二、判据（三卡）

### 2.1 五态（UX-STATES-01）

| 态 | 触达动作 | PASS 的最小证据 | FAIL 的判定 |
|---|---|---|---|
| 空 | 筛选到 0 条 | 文案 + 下一步动作（如"新建"按钮） | 白屏 / 无动作 |
| 加载 | Slow 3G 刷新 | 骨架屏可见 | 白屏或闪烁 |
| 错误 | 拦截 API 返回 500 | 错误说明 + 重试按钮 | 无提示 / 页面崩溃 |
| 无权限 | `e2e-viewer` 访问写操作 | `Forbidden` 组件 | 静默失败 / 报 500 |
| 成功 | 完成一次写操作 | 具体 toast 文案 | 无提示 / "操作成功"泛词 |

**N-A 的合法条件**：
- `news`：纯 redirect，5 态全 N-A
- `login`：空态/列表态 N-A
- 只读页（`logs` 等）：成功态 N-A

**禁止**：grep 到 `EmptyState` 就判 PASS（那是"有代码"不是"可触达"，历史坑 H4）

### 2.2 键盘（KEYBOARD-01，按 B1 默认 A 最小集）

| 项 | 动作 | PASS | FAIL |
|---|---|---|---|
| K1 Tab 顺序 | 从首元素 Tab 到末元素 | 与视觉顺序一致 | 跳跃/回跳 |
| K2 主操作可聚焦 | Tab 到新建/保存，Enter | 触发成功 | 不可达 / 不触发 |
| K3 Esc 关弹窗 | 打开弹窗按 Esc | 关闭无副作用 | 不关闭 |
| K4 焦点可见 | Tab 观察 | 有可见 ring | `outline:none` 无替代 |

**明确不在范围**：焦点陷阱、⌘/Ctrl+S 全局（见 `06 §B1`）

### 2.3 375px（MOBILE-375-01）

| 项 | 动作 | PASS | FAIL |
|---|---|---|---|
| M1 无溢出 | 量 `document.documentElement.scrollWidth` | ≤ 375 | > 375（记数值） |
| M2 核心操作 | 列表：搜索+新建+行操作；表单：提交+取消 | 均可达且生效 | 任一项不可达 |
| M3 命中区 | `getBoundingClientRect()` | ≥ 44×44 | < 44（记尺寸） |
| M4 卡片模式 | 看列表是否切卡片 | 无表格横滚 | 表格横向滚动 |

**M1 必须是数字**，不能写"无溢出"。

## 四、完成定义

```text
Done =
  所有权内 diff 符合任务
  ∧ 验收条目逐条有 PASS/FAIL/UNKNOWN
  ∧ 证据可复现（一周后的人不用问原作者）
  ∧ 守卫通过
  ∧ 无新增同类错误
  ∧ 未改冻结契约
```

**关键**：本轮"可复现"的具体含义 = 每格有"做了什么 + 看到什么"，能照着再走一遍。

## 五、证据要求

```text
docs/design/06_validation/evidence/V15/<卡号>/
  ├── execution.md     5W1H + 改动文件 + 验收逐条 + 命令输出 + UNKNOWN
  └── matrix.md        42 行 × N 列，每格带判据
```

**matrix.md 格式示例**：
```markdown
| 页面 | 空态 | 加载态 | 错误态 | 无权限 | 成功态 |
|---|---|---|---|---|---|
| articles | PASS：搜索 zzz-no-match → 显示"没有匹配结果"+新建按钮 | PASS：Slow3G 刷新 → 3 行骨架 | PASS：拦截 /api/articles 500 → "加载失败"+重试 | PASS：e2e-viewer 点新建 → Forbidden | PASS：新建"t1"→"文章已创建" |
```

**反例（判 FAIL）**：
```markdown
| articles | PASS | PASS | PASS | PASS | PASS |   ← 无判据
```
