## 三、本轮新增事实（改变颗粒度与工作量估算）

### F1 · 375px 已有 4 个 e2e 用例，但只覆盖 3/42 路由

**三层证据链**：

1. **文件存在**：`tests/e2e/mobile-375.spec.ts`，`grep -c "^test("` → **4**
2. **断言口径已定**（`mobile-375.spec.ts:57-63`）：
   ```js
   test("375：整页无横向溢出（scrollWidth = 375）", async ({ page }) => {
     for (const path of ["/manager/articles", "/manager/content-hub", "/manager/enrollment-offerings"]) {
       await page.goto(path, { waitUntil: "load" });
       await page.waitForTimeout(500);
       const sw = await page.evaluate(() => document.documentElement.scrollWidth);
       expect(sw, `${path} 横向溢出 scrollWidth=${sw}`).toBeLessThanOrEqual(375);
     }
   });
   ```
3. **覆盖面**：该用例只遍历 3 条路径；全量 `find src/app/manager -name page.tsx | wc -l` → **42**

**结论**：M1（无横向溢出）的**判定写法可直接复用**，但**覆盖范围要从 3 扩到 42**。不是"从零写脚本"，是"扩展现有 spec"。

**反向检验**：会不会有其它文件也覆盖了 375 溢出？
→ `grep -rln "scrollWidth" tests/` 仅命中 `mobile-375.spec.ts` 一处。**结论成立。**

### F2 · 42 页按实现方式分 27 + 15 两类

**三层证据链**：

1. **分类命令**：
   ```bash
   for f in $(find src/app/manager -name page.tsx); do
     grep -q "CrudPage" "$f" && echo A || echo B
   done | sort | uniq -c
   # → 27 A / 15 B
   ```
2. **A 类共用渲染器**：`src/components/manager/CrudPage.tsx` 提供
   - `:333` `if (isForbidden(error)) return <Forbidden message={error.message} />;`（无权限态）
   - `:370` `<PageHeader title={...} description={...} actions={createBtn} />`（页头）
   - 文件头注释（`:1-10`）声明"五态：骨架 / 空（带下一步）/ 错误 + 重试 / 无权限 / Toast"
3. **B 类 15 页清单**（逐文件 `grep -v CrudPage`）：
   `articles`、`chat-history`、`collect-items`、`content-hub`、`home-blocks`、`knowledge-bases`、`llm-providers`、`login`、`media`、`news`、`notify-rules`、`manager`、`publish-jobs`、`settings`、`wechat-accounts`

**结论**：A 类 27 页的五态判定**共用一套判据**（同一渲染器 → 同一行为），B 类 15 页逐页独立。

**反向检验**：A 类里会不会有页面绕过 CrudPage 自己写五态？
→ 27 页中 `grep -c "EmptyState\|ErrorState"` 多为 0（因由 CrudPage 提供），说明确实走统一渲染。**结论成立。**
