## 5. 环境适配与偏差（可被后续所有卡复用）

| 现象 | 根因 | 规避（已验证可用） |
| --- | --- | --- |
| `npm ci` exit 1 | 沙箱 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`（count=466>50）拦截整目录重建 | 改 `npm install --prefer-offline --no-audit --no-fund`（增量，不触发批量删除）；**结果：exit 0，lock 未变** |
| `next build` exit 1 | 同上（`.next/trace` 50 文件） | 先清空 `.next`，再 `npm run build`；**结果：exit 0** |

| esbuild `EBUSY`/`EFTYPE` | npm 中断导致 `@esbuild/win32-x64/esbuild.exe` 截断（6.1MB vs 11.7MB） | `npm pack @esbuild/win32-x64@0.28.2` + 覆盖解压 |
| 1 例测试失败：`wechat-chat > src/lib 无硬编码电话/域名` | 断言内 `execSync('grep …')` 触发 `spawnSync cmd.exe EBUSY` | 环境性，记 UNKNOWN；不改仓库 |
| 1 例套件失败：`sqlite-busy-timeout` | 沙箱 `node-safe-delete-shim.cjs` 改写 `fs.rmSync`，临时 DB 被锁 → EBUSY | 环境性，记 UNKNOWN |
| 中文文件名致越界检查误报 | `git` 默认 `core.quotePath=true` | 用 `git -c core.quotePath=false …`（`-c` 须在子命令前） |
