## LCP-01 · 测量口径

| 层 | 凭据 |
|---|---|
| **E1** | Web Vitals good 阈值 CLS ≤ 0.1、LCP ≤ 2.5s（针对**真实用户**） |
| **E2** | N/A（本轮不改代码） |
| **E3** | `evidence/V19/D1-FIX/after.md`：模拟 3.1~3.3s / 无节流见原文 / **真实 136ms**；CLS 模拟 0.208→0、真实 0 |

### 关键矛盾

| 口径 | LCP | 与 good 阈值 |
|---|---:|---|
| Lighthouse 模拟（Slow 4G） | 3.1~3.3s | 未达 |
| 真实浏览器 | **136ms** | **远超优** |

**差 24 倍。**且模拟下 LCP 元素在两轮间漂移（footer `<p>` ↔ logo `<img>`），元素不稳定 = 指标不可复现。

### CLS 的归因（已解决）

```
after 两轮 CLS 0.208 单一 layout-shift，score=0.2078
节点 = <footer class="bg-[#da251d] text-white/80">
```

CLS 已从 0.208 改进到 0（模拟口径也归零），**不再是遗留问题**。
