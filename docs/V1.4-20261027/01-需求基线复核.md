# 01 需求基线复核（V1.4）

> 本轮独立复核，不默认上一轮台账完整。每条 MUST 必须能改写成**一句可验证的话**，否则标"待澄清"。

## 1. 复述与拆解

**核心问题**：把弘道教育的官网（前台展示 + AI 客服 + 在线报名）与内容运营后台（文章/课程/校区/媒体/采集/知识库/多模型/公众号发布/邮件提醒）合并成一个系统，前台外观必须与旧站 `origin/main@94dbbbb` 一致，后台要做到"顶级设计、极度友好"，并且旧站有的功能一个都不能少。

**关键角色**
| 角色 | 边界 |
|---|---|
| 访客（未登录） | 浏览前台全部页面、AI 客服、提交报名 |
| 运营/编辑（Viewer/Editor） | 后台内容 CRUD、审核、发布 |
| 管理员（Admin） | 上述 + 用户/角色/设置/模型/知识库 |
| 超管（SuperAdmin） | 上述 + 审核权（ADR-017 独享）+ 越权边界 |
| 系统（定时任务） | 采集、发布、通知、余额巡检 |

**系统边界**
- 内：`src/app/(web)`、`src/app/manager`、`src/app/api`、Prisma/SQLite、本地文件存储、进程内调度
- 外：微信公众号 API、SMTP、LLM 供应商（ModelScope/OpenAI 兼容）、Coze dataset、被采集站点
