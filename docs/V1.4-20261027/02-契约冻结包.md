## ① API 契约

**信封**（`common.ts:28`）

```ts
apiEnvelopeSchema = z.object({
  code: z.number(),
  data: z.unknown().nullable(),
  message: z.string(),
})
```

**分页**（`common.ts:42-53`）

```ts
paginationSchema = { page ≥1, limit 1..100, total ≥0, totalPages ≥0 }
listQuerySchema  = { page 默认1, limit 默认10(max100), keyword? ≤200 }
paginated<T>(list, pagination) → { list, pagination }
```

**路径与方法命名约定**（实测 126 个 `route.ts` 归纳）

| 操作 | 形态 | 示例 |
|---|---|---|
| 列表 | `GET /api/<资源>?page&limit&keyword` | `/api/articles` |
| 详情 | `GET /api/<资源>/[id]` | `/api/articles/12` |
| 新建 | `POST /api/<资源>` | 返回 `{ id }` |
| 更新 | `PUT /api/<资源>/[id]` | 全量 |
| 部分更新 | `PATCH /api/<资源>/[id]` | 状态类（如 `article:publish`） |
| 删除 | `DELETE /api/<资源>/[id]` | 软删或硬删由资源定义 |

**鉴权**：管理端接口经 `withApi`，未登录 401、无权限 403（`src/lib/api-handler.ts`）。

**前端能否只凭契约写调用层？** → 能。`tests/contract/route-handlers.gen.ts` + `route-inventory.json` 已从路由生成清单，证明清单与实现同源。

## ② Errors 契约

**错误码枚举**（`common.ts:64-74`）

```ts
errorCodes = {
  OK: 200, BAD_REQUEST: 400, UNAUTHORIZED: 401, FORBIDDEN: 403,
  NOT_FOUND: 404, CONFLICT: 409, TOO_MANY_REQUESTS: 429,
  SERVER_ERROR: 500, BAD_GATEWAY: 502, SERVICE_UNAVAILABLE: 503,
}
```

**HTTP 状态 ↔ code 映射**：二者取值相同（`code === HTTP status`），由 `src/lib/api-response.ts` 统一构造。

**429 附加头**：`Retry-After`（`api-handler.ts:187`，V11-SEC-02）。

**前端展示**：失败优先用后端 `message`，缺省回落到 `toastCopy.failed` / `.network` / `.forbidden`（`common.ts:88+`）。

**已知失败路径覆盖核查**

| 失败路径 | 是否有码 | 证据 |
|---|---|---|
| 未登录 | 401 ✅ | auth 契约测试 |
| 无权限 | 403 ✅ | `ux-states` e2e（viewer 访问 users） |
| 资源不存在 | 404 ✅ | CRUD 契约测试 |
| 唯一键冲突 | 409 ✅ | 角色删除/校区重复 |
| 限频 | 429 ✅ | `chat-guard` 单测 |
| 上游 LLM 全不可用 | 503 ✅ | `llm-limits` 单测 |
| 上游 LLM 部分失败 | 502 ✅ | `chat-stream-sse` 契约 |
| 服务器内部错误 | 500 ✅ | `ux-states` 500 场景 |

## ③ Identity 契约

**核心类型**（`auth.ts`）

| 类型 | 用途 |
|---|---|
| `loginRequestSchema` | 登录入参 |
| `sessionUserSchema` | 会话用户（id/username/nickname/roles/permissions） |
| `jwtClaimsSchema` | JWT 声明（含 exp） |
| `permissionCatalog` | 权限码清单（按资源 × 动作） |
| `superAdminOnlyPermissions = ["review:edit"]` | **超管独享**（ADR-017） |

**权限边界（硬约束）**

| 边界 | 规则 | 守卫 |
|---|---|---|
| 管理端 vs 前台 | 管理端接口全部经 `withApi` + 权限校验；前台公开接口仅 chat/apply 等白名单 | `src/lib/api-handler.ts` |
| 越权自我提权 | 不能修改自己所属角色、不能授予自身不具备的权限 | `roles/PUT` 单测 |
| 超管保护 | 不能删除超管账号、不能删除当前登录账号 | `users/DELETE` 单测 |
| 审核权 | `review:edit` 仅 SuperAdmin | `superAdminOnlyPermissions` |
| 会话伪造 | chat 会话必须服务端 HMAC 签名，body 与 cookie 不一致即 400 | `chat-service.ts` + 单测 |

## ⑥ UX States 契约

```ts
uxStateSchema = z.enum(["loading", "empty", "error", "forbidden", "success"])
toastCopy = { saved, created, deleted, updated, failed, network, forbidden, ... }
```

**每种状态的判定条件**

| 状态 | 触发条件 | 组件 |
|---|---|---|
| loading | 请求未返回 | 骨架屏 |
| empty | 返回 200 且 list.length === 0 | EmptyState |
| error | 请求失败（非 401/403） | ErrorState（含重试） |
| forbidden | 401/403 | Forbidden 视图 |
| success | 返回 200 且有数据 | DataTable |

**e2e 覆盖**：`tests/e2e/ux-states.spec.ts`（对 articles / llm-providers / knowledge-bases / collect-items 各测 403/500/空态 + 首屏骨架 + 成功态）。
