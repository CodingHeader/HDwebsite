## 4. 软删除与生命周期

| 域 | 策略 | 证据 |
|---|---|---|
| `Article` / `ContentItem` | 状态字段（offline/draft），非物理删除 | `CONTENT_ITEM_STATUSES` |
| `KnowledgeFile` | 回收站 → 彻底删除 | `e-kb-manage` e2e「删除→回收站→恢复」 |
| `Media` | 软删 + 孤儿扫描脚本 | `scan-orphan-uploads.mjs` |
| `User` | 禁止删除超管/当前登录 | `users/DELETE` 单测 |
| 上传文件 | `DATA_DIR` 卷承载，不进镜像 | `next.config.ts` excludes |
