## 2. 声明的偏差与局限

1. **未提供 `gen_tasks.py`**：V0.8 以 gen_tasks.py 为卡唯一源（含环/重叠检测）。本轮仅 4 卡、手工核对（上表第 2 行），为避免为"将来可能需要"提前抽象（规划总指令 §13），不再写生成脚本。若后续轮次卡数回升，恢复脚本化。
2. **验证者身份**：子代理担任独立验证者，机制隔离见 01 §4；这是当前环境下最强隔离，不是绝对隔离。
3. **CI 结论的证据形态**：CI 产物（日志/截图 diff）经 GitHub API 下载存入 evidence；其原始在线链接与 run id 一并记录，可复核。
4. **Windows 本地 visual 不可作门禁**：字体渲染差异（V0.7 实测），visual 门禁只认 CI；本地仅做"能渲染、高度合理"的冒烟。
5. **凭据**：全程不落仓库、不落文档；轮询 CI 用 PAT 临时文件（600），用后即删。
