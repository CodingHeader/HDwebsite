## 归属
- 所属切片：S1
- 来源需求/证据：`docs/V0.9-20261023/00-事实基线.md` §2（CI 9 连败取证）；V8-REL-01 blocked 解除条件
- 执行者：主代理

## 目标
推送后 CI 三 job（gate / visual / docker）全部可运行且 gate 绿；visual 进入可分诊状态；docker 结论给出 REL-01 裁决依据

## 输入
- 文档：00-事实基线.md、01-需求复核与辩证分析.md、04-连续执行协议.md
- 代码：`.github/workflows/ci.yml`、`prisma/seed-visual.ts`、`prisma/schema.prisma`（只读，FK 依据）、`prisma/seed.ts`（只读，Role/User 字段依据）

## 输出
- `.github/workflows/ci.yml`（gate 加 Prepare build DB；新增 docker job）
- `prisma/seed-visual.ts`（外键自足：ensureVisualAuthor + 动态 authorId）
- `docs/design/06_validation/evidence/V9/CI-01/**`

## Execution Steps
1. [ ] gate job：「Prisma generate」后新增「Prepare build DB」= `npx prisma migrate deploy`（env 已有 `DATABASE_URL=file:./prisma/ci-build.db`）；注释写明因果（静态导出查库，构建前必须 migrate）
2. [ ] seed-visual.ts：新增 `ensureVisualAuthor()`——已有活跃用户则复用其 id；否则 upsert `Role(super-admin)`（permissions JSON-in-String `["*"]`）后 create User（固定凭据哈希常量，仅外键锚点，不参与渲染）；写模式入口调用；articles 工厂 `authorId` 改动态值
3. [ ] 新增 docker job：`docker build` → 起容器（e2e 占位 JWT_SECRET/ENCRYPTION_KEY，DB 指向容器内临时文件）→ `curl /api/health` 探活 → 结论入证据
4. [ ] 本地验证：`npx tsx prisma/seed-visual.ts --check`（预期 exit 1 报行数差）→ 写模式（幂等）→ 再 `--check`（预期 10/10 ✓）→ 全量门禁四连（lint/typecheck/test/build）
5. [ ] yaml 语法校验；提交推送；API 轮询 CI 三 job 结论

## 验收标准
- [ ] 本地 seed-visual：写模式成功且二次 `--check` 全 ✓（幂等证明）
- [ ] 本地全量门禁四连 exit 0
- [ ] CI gate job 绿（Build 步通过）
- [ ] CI visual job 的 Prepare DB 步通过（visual 测试本身允许 fail——那是 VIS-03 的输入）
- [ ] CI docker job 有明确结论（绿=REL-01 可解 blocked；红=按 08 V9-Q2 默认方案处理）
- [ ] 全部输出含 run id 与可复现命令
