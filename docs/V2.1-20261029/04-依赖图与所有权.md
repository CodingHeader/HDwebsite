## 二、并行判定（机械规则）

可并行 ⟺ ① 无共享可变状态 ∧ ② 依赖的契约已冻结且机器可校验 ∧ ③ 文件所有权不相交 ∧ ④ 不共用同一迁移版本号

| 卡 | ① 无共享状态 | ② 契约已冻 | ③ 所有权不相交 | ④ 无迁移 | 判定 |
|---|---|---|---|---|---|
| ENV-01 | ✓（改 `scripts/`） | ✓（启动契约 §二） | ✓ | ✓ | **可并行** |
| ENV-02 | ✓（改 `api/health`） | ✓（端口契约 §三） | ✓ | ✓ | 需 ENV-01 先完成（同改 `start-next.mjs`）→ **串行** |
| AUD-01 | ✓（只读 + 写 evidence） | ✓（审计契约 §四） | ✓ | ✓ | **可并行** |
| AUD-02 | ✓（可能改 FourCards） | ✓ | ⚠️ 若回滚则与 AUD-01 的只读冲突 | ✓ | 需 AUD-01 先完成 → **串行** |
| PAR-01 | ✓（只读 + 写 evidence） | ✓ | ✓ | ✓ | **可并行** |
| PAR-02 | ✓（只读 writing evidence） | ✓ | ✓ | ✓ | 需 PAR-01 → **串行** |
| E1 | ✗（改 `state.json`） | — | — | — | **串行，最后** |

**三组之间的并行结论**：

| 组 | 可并行依据（逐条） |
|---|---|
| ENV-01 ‖ AUD-01 ‖ PAR-01 | ① ENV-01 改 `scripts/`、AUD-01 只读 `src/components/web`、PAR-01 只读 `src/app/api`——三者路径不相交<br>② 三份契约（启动/审计/对等）均已在 `02-契约与不变量.md` 冻结<br>③ 文件所有权矩阵无重叠（见 §三）<br>④ 本轮无迁移 |

**结论：ENV-01、AUD-01、PAR-01 三卡可同时下发。**
