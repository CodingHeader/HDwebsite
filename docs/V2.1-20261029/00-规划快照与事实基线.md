## 二、核心发现（决定整个规划方向）

### 2.1 ★ `:3000` 端口运行的不是 HDwebsite

这是用户报告「界面呈现移动端、设计/导航/功能全变」的最强解释。

**证据链三级**：

| 层 | 证据 |
|---|---|
| E1 来源 | 用户报告："启动后的界面…界面设计、菜单导航、功能等等都发生了大变化" |
| E2 实现 | 本项目 `package.json` 的 dev 端口 = **6789**，start 脚本默认 `PORT \|\| "6789"`（`scripts/start-next.mjs:17`） |
| E3 验证 | 见下 |

**E3 实测**：

```bash
$ netstat -ano | grep ":3000 " | grep LISTENING
TCP    0.0.0.0:3000    0.0.0.0:0    LISTENING    14304

$ wmic process where "ProcessId=14304" get CommandLine
"node.exe" E:\Code\Aidean\node_modules\.pnpm\next@15.5.28_...\start-server.js
                       ↑ Aidean 项目，Next 15.5.28

$ curl -s http://127.0.0.1:3000/ | grep -o '<title>[^<]*</title>'
<title>Aidean · AI模型天梯图平台</title>

$ curl -s http://127.0.0.1:3000/manager -o /dev/null -w "%{http_code}"
404                     ↑ Aidean 无 /manager
```

**首页关键词计数（`/tmp/home.html`，414,650 字节）**：

```bash
'da251d' → 0 次      # HDwebsite 品牌红，Aidean 完全没有
'弘道'   → 0 次
'Aidean' → 954 次
'天梯图' → 57 次
```

**截图交叉验证**（`.cache/v21/3000-desktop.png`、`3000-mobile.png`）：

> 独立视觉核查结论：「品牌是 Aidean（AIDEAN）…AI 大模型与云服务选型…不是教育产品…**不是同一产品，也不是同一品牌视觉页面**」

**结论**：用户若打开 `http://localhost:3000`，看到的是**另一个项目（Aidean）**，其设计、导航、功能与 HDwebsite 毫无关系。这与"大变"的描述完全吻合。

**⚠️ 但这不排除另有真实缺陷**——见 2.2、2.3。

### 2.2 HDwebsite 自身在 1440 视口渲染正常

**E3 实测**（启动于 `PORT=6789`，Playwright 视口取证）：

```json
desktop {"docW":1440,"vw":1440,"navBranches":[
  {"cls":"md:hidden flex items-center justify-star","disp":"none","w":0},
  {"cls":"hidden md:flex items-center justify-cent","disp":"flex","w":1344}],
  "bodyBg":"lab(100 0 0)"}

mobile  {"docW":375,"vw":375,"navBranches":[
  {"cls":"md:hidden flex items-center justify-star","disp":"flex","w":343},
  {"cls":"hidden md:flex items-center justify-cent","disp":"none","w":0}]}
```

**中间断点复核**（这是"是否错误落到移动端"的关键）：

```json
768  {"navBranches":["none","flex"],"docW":768}
1024 {"navBranches":["none","flex"],"docW":1024}
1280 {"navBranches":["none","flex"],"docW":1280}
```

**判读**：`md`（768px）及以上全部命中桌面分支 `hidden md:flex`，移动分支 `md:hidden` 为 `none`。**断点行为正确，无"桌面渲染成移动端"的缺陷。**

**Tailwind 产物复核**（排除断点未编译的可能）：

```bash
$ grep -o "@media[^{]*min-width:[^)]*)" .next/static/chunks/22gm22yx3t4w5.css | sort -u
@media (min-width:40rem)   # sm 640
@media (min-width:48rem)   # md 768
@media (min-width:64rem)   # lg 1024
@media (min-width:80rem)   # xl 1280
@media (min-width:96rem)   # 2xl 1536
```

**视觉核查结论**（`.cache/v21/home-desktop.png`）：

> 「桌面宽屏布局…主导航为**横排**，包括"网站首页、关于我们、学历提升…"…品牌名"弘道教育"…红色顶部欢迎条、红色横向导航条和红色主视觉都很明显，是典型的官网桌面版风格」

**结论**：`http://127.0.0.1:6789` 上的 HDwebsite 外观**符合 main 风格**（红横幅 + 横排导航）。

### 2.4 前台 className **值**差异（不是缩进）

用 `className="…"` 精确值集合做 `comm` 比对（剔除缩进/格式噪声）：

| 组件 | main 独有 | HEAD 独有 | 判定 |
|---|---:|---:|---|
| TopBanner | 0 | 1 | 新增包裹层，值未变 |
| StatsBanner | 0 | 0 | **完全一致** |
| FourCards | 2 | 2 | **值有实质变化** |
| Navbar | 1 | 2 | **值有实质变化** |
| Banner | 0 | 2 | 新增按钮类 |

**FourCards 明细**：

```
main 独有：
  className="grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 gap-4 max-w-5xl mx-auto"
  className="relative flex-1"
HEAD 独有：
  className="absolute inset-0 bg-black/40 group-hover:bg-black/30 transition-colors"
  className="absolute inset-0 bg-cover bg-center transition-transform duration-300 group-hover:scale-105"
```

**Navbar 明细**：

```
main 独有：className="md:hidden flex items-center justify-between h-[45px]"
HEAD 独有：className="md:hidden flex items-center justify-start overflow-x-auto h-[45px] [scrollbar-w…"
          className="relative shrink-0"
```

**Navbar 的差异有 ADR 依据**：源码注释标注「V10-Q1（用户 2026-10-24 授权的最小冻结豁免）：9 个导航项在 ≤595px 横排溢出…改为条内横向滚动」。

**FourCards 的差异无出处**：`grid` 追加 `${gridAlignClass}` 是 A3 卡的配置能力（默认为空时逐字一致），但 `relative flex-1` → `absolute inset-0 …` 是**结构性改写**（原为 flex 布局的图标容器，改为绝对定位覆盖层）。**需审计**。
