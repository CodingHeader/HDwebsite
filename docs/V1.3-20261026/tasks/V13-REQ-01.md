## Execution Steps
1. [ ] 建立 ledger 表头：`需求ID | 条目原文 | 判定 | 证据路径 | 备注`
2. [ ] 逐条判定，**判定规则**：
   - `PASS`：有代码 + 有可复现命令/测试证据（必须写路径）
   - `UNKNOWN`：有实现但环境限制无法验证（必须写原因，如"真实微信凭证缺失"）
   - `N-A`：需求已被 ADR 替代或明确不做（必须写 ADR 编号）
3. [ ] 仅对 `PASS` 项在原需求文档勾选 `- [x]`，并在行尾加 `（证据：<路径>）`
4. [ ] `UNKNOWN` 项**保持未勾选**，在 ledger 标注
5. [ ] 汇总：PASS / UNKNOWN / N-A 三类计数，并与 102 对齐（**必须相等**）
6. [ ] 证据：ledger + 勾选后的 `git diff --stat`

## 验收标准
- [ ] 102 条**逐条**有判定，无遗漏（计数对齐）
- [ ] 每条 `PASS` 附证据路径（文件或命令）
- [ ] `UNKNOWN` 全部有原因，且未被勾选
- [ ] `N-A` 全部有 ADR 依据
- [ ] 未擅自修改需求原文措辞（只勾选 + 追加证据路径）
