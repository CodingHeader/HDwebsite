- 选 10：改 `settings-registry.ts` 默认值 + `settings-registry.test.ts` 断言；`REQ-F-009` 不改。
- 选 20：`V13-RL-01` 的默认值改回 20，并把 `REQ-F-009:38` 的口径修订为 20（附 ADR-034 依据）。
