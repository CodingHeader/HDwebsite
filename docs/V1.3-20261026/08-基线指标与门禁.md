## 二、三项必须携带的口径（V1.3 新增纪律）

### 2.1 构建时间戳（因 G2 的教训）

任何 e2e 结论必须同时记录：

```
BUILD_ID mtime = <ISO>
src 最新 mtime = <ISO>
关系 = BUILD_ID > src（fresh） / BUILD_ID < src（stale，结论作废）
```

`V13-E2E-FRESH-01` 已在 `tests/e2e/global-setup.ts` 加硬校验：stale 直接抛错，不再静默测旧构建。

### 2.2 串行执行（因并发假红的教训）

**禁止**并行跑 `npm run build` 与 `npm test`。实测并行会出 `Hook timed out in 10000ms`（2 文件），单跑与串行全量均全绿。

### 2.3 visual 只有 Linux CI 可判

- 参照图在 Linux/CI 生成（`tests/visual/reference/`，45 张）。
- Windows 字体渲染差异无法与真实样式差异分离（V0.7 实测 19 pass / 26 fail 全为渲染/数据差异）。
- 基线重生成**只能**经 `workflow_dispatch` + `visual_update_ref=true`，禁止本机生成、禁止手工改 png。
