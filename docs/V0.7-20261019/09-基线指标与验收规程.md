## 2. 完成定义（唯一口径，与 AGENTS.md §6 一致）

Done = 所有权内 diff 符合任务 ∧ 验收条目逐条有 PASS/FAIL/UNKNOWN ∧ 自动测试或脚本可复现（**干净检出、无 .env、无 dev.db**）∧ 证据一周后可复现 ∧ 守卫通过 ∧ 无新增同类错误 ∧ 未改冻结契约。

## 3. 防自证循环

- 验收标准：本规划包写定（任务卡"验收标准"节），执行者不得改写。
- 执行：卡上"执行者"。
- 判定：独立验证者（不得是该卡执行者），只看 `git diff <起点>..<终点>` + 运行结果，输出一行：`<卡号> PASS|FAIL|UNKNOWN — <理由一句>`，写入 `docs/design/06_validation/evidence/V7/<卡号>/<卡号>-verify.md`。
- 指派：Hark 的卡由 P2 验；P1 的卡由 P2 验；P2 的卡由 P1 验；P3 的卡由 P1 验（负载均衡，且均不自验）。
