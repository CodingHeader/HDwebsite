# 02 契约增量与数据模型

**唯一源**：`src/contracts/**`（zod，冻结面基线 f158501，V0.7 期间经 CCR 有增量，例如 applySubmitSchema）。本轮**不新增任何契约字段，不新增任何迁移**。

| 契约 | 本轮变化 | 说明 |
|---|---|---|
| ① API | 无 | T-04 对 5 条路由，要么迁移且响应体不变，要么登记豁免（ADR-037） |
| ② Errors | 无 | UI-01 的无权限态由现有 403 码驱动；不新增错误码，若需要则升级到 CCR |
| ③ Identity | 无 | E1~E5 规则已在 SEC-01（V0.7）落地 |
| ④ Resources | 无 | file 路由防路径穿越补负向用例（T-04） |
| ⑤ Events | 无 | SSE 帧（chat/stream）按现有定义补契约测试（T-02） |
| ⑥ UX States | **补全矩阵** | 22 资源 × 5 态 = 110 格，由 resource-meta 派生（UI-01） |

**数据模型**：7 个迁移（20261011052216_init … 20261014073639_p12_knowledge_base），本轮 0 新迁移。VIS-01 只写数据（seed），不改 schema。
**迁移编排**：若某卡被迫需要迁移 → 视为契约变更 → 停止，交 Hark 走 CCR，版本号顺延为 `2026102x_v8_<name>`，同一时间只允许一个迁移在途。
**依赖（冻结面）**：package.json 和 lock 的修改只允许 SEC-01 → SEC-02 → SEC-03 按顺序串行进行（Q1 授权后）。
