## 二、逐卡定向检查

### FIX-01 · 空态动作（6 页）

```bash
npx tsc --noEmit
npx vitest run src/components/manager/__tests__/ 2>/dev/null || true
```

**人工验证（6 页逐页）**：起服务后对 `articles`/`chat-history`/`collect-items`/`content-hub`/`home-blocks`/`knowledge-bases` 各做一次「筛选到 0 条」，确认 `empty-state` 内出现可点动作。

**判据**：`empty-state` 容器内 `button, a` 数量 ≥ 1，且该动作文案与空态描述同源。

### FIX-02 · toast 实体名（4 页）

```bash
npx tsc --noEmit
```

**人工验证（4 页）**：`banners`/`enrollment-offerings`/`content-hub`/`publish-jobs` 各新建一条，断言 toast 的 **Title + Description 合并文本**包含该记录名，且不含「已创建」「已保存」「操作成功」作为唯一内容。

**判据**（同 B1 v2 判据 §3.2）：
```
PASS = toast-success 可见
     ∧ 合并文本包含所建实体名
     ∧ 该实体名 ∉ {已创建, 已保存, 操作成功}
```

### FIX-03 · `collect-tasks` 搜索

```bash
npx tsc --noEmit
npx vitest run src/lib/crud-resources 2>/dev/null || true
```

**人工验证**：`/manager/collect-tasks` 搜索 `zzz-no-match-zzz`，断言返回 0 行且出现 `empty-state`。

**若走路径 B（隐藏搜索框）**：断言页面无搜索输入框。

### B2 · 键盘验收

```bash
git status --short src tests prisma     # 必须为空（本卡只写 evidence）
```

**产出机检**：
```bash
grep -c "^| src/app/manager" docs/design/06_validation/evidence/V19/B2/matrix.md   # 期望 43
grep -c "待核" docs/design/06_validation/evidence/V19/B2/matrix.md                 # 期望 0
```

**K3 必须有运行时记录**（卡片硬要求，缺此项整卡 FAIL）。

### B3 · 375px 验收

```bash
npx playwright test -c tests/e2e/playwright.config.ts mobile-375
git diff tests/e2e/mobile-375.spec.ts | grep "toBeLessThanOrEqual(375)" && echo "FAIL 阈值被改" || echo "PASS"
```

**产出机检**：同 B2，43 行 / 0「待核」。

### D1-FIX · CLS/LCP

```bash
npx lighthouse --version 2>/dev/null || echo "UNKNOWN: Lighthouse 不可用"
```

**判据**：CLS ≤ 0.1、LCP ≤ 2.5s（good 阈值）。改进前后各测一次，记录数值。

**若 Lighthouse 不可用** → 记 UNKNOWN，**不得冒充 PASS**。

### E1 · 收口

**唯一一次全量门禁（串行）**：

```bash
npm run lint && npm run typecheck && npm test && npm run build
npm run test:visual          # 前台视觉门禁
npm run test:e2e             # 若环境允许
```

| 时点 | 动作 |

## 四、已知环境陷阱（沿用 B1 经验）

| 陷阱 | 处置 |
|---|---|
| `npm test` 多 worker 并发抢 SQLite → 假红 | 用 `--no-file-parallelism`；已知预先存在问题，非本轮引入 |
| 登录限流 `10/60s` | 全程用 `storageState`，登录 ≤2 次 |
| 手工起服务缺 `JWT_SECRET` | 复用 `tests/e2e/global-setup.ts`，它注入正确 secret |
| `e2e.db` 与 `dev.db` 混淆 | `dev.db` 已删，一律用 `e2e.db` |
| win32 视觉回归像素差异 | 属 Linux 基线字体差异，不采信本地结果，记 UNKNOWN |
