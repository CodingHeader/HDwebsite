## 2. sqlite-busy-timeout flake 观察（V10-T-06）

- V9-V-01 期间 1 次失败（验证者环境，shuffle 负载下）；失败断言未固化（当时未捕获细节）。
- 本轮实测：单文件连跑 10 次 4/4 全绿；全量 shuffle 4 轮 1712/1712 全绿（该文件 0 失败）。累计自首次观察 10+ 轮绿。
- 机制：3 个用例涉子进程 spawn + 真实锁竞争（持锁 400ms 窗口），CI/shuffle 负载下子进程启动耗时抖动是唯一合理解释；断言本身与被测 busy_timeout(5000ms) 无关。
- 处置：3 个用例超时 20s→40s（保险，不放松断言）；若再复现，按卡面熔断规则带断言细节立卡。
